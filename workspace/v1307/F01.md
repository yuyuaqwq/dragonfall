# 任务卡 F01 意见#28 逃跑受等级差+速度差影响（先读 FRAMEWORK.md 公共框架）

## 背景
玩家意见#28（已回滚为 new）：『逃跑受等级差距或者速度差距的影响，越多级跑不掉，尽量避免玩家跑高级区域』。鱼鱼拍板做。
现状：game/core/constants.py:19 `FLEE_CHANCE = 0.75`（固定逃跑率），game/battle.py:2005-2022 `_do_flee` 里 `if random.random() < C.FLEE_CHANCE:` 纯固定概率。
目标：逃跑成功率 = 基础 0.75 ± 等级差/速度差修正，clamp 到 [0.15, 0.95]。

## 任务（精确改动点）
## 方案（数值硬约束，按此实现）
1. 在 constants.py 新增（或原地调整）：
   - `FLEE_CHANCE = 0.75` 保留为基础值
   - `FLEE_LEVEL_STEP = 0.05`（每 1 级等级差 ±5%）
   - `FLEE_SPD_STEP = 0.01`（每 1 点速度差 ±1%）
   - `FLEE_MIN = 0.15` / `FLEE_MAX = 0.95`（clamp 下限/上限）
2. `_do_flee` 计算：
   ```python
   lv_diff = 玩家level - 敌人level   # 玩家等级高 = 正 = 更容易逃
   spd_diff = 玩家spd - 敌人spd      # 玩家快 = 正 = 更容易逃
   flee_rate = clamp(FLEE_CHANCE + lv_diff*FLEE_LEVEL_STEP + spd_diff*FLEE_SPD_STEP, FLEE_MIN, FLEE_MAX)
   if random.random() < flee_rate: ...
   ```
3. 敌人等级/速度获取：看 battle 里 enemy dict 是否有 lv/spd 字段；若 enemy dict 没有 spd，查 `_enemy_stats` 或 enemies 构建处（build_monster 产物）取。**速度无法可靠获取时退化为仅等级差**，并在报告里说明。
4. 文案：失败提示『💨 逃跑失败！被追上了！』可在前面加原因（如敌方比你高 N 级/更快，几乎逃不脱），保持既有风格即可；worldboss/pvp 分支（2006-2013）完全不动。
5. 策划案 27 章 366 行是旧口径——**别改**，F12 统一同步。
