# 任务卡 F07 意见#22 喂养只能吃食物（先读 FRAMEWORK.md 公共框架）

## 背景
玩家意见#22（回滚为 new）：『喂养改成只能吃食物类的』。
现状（审计确认）：social.py:987 `FOOD_TYPES = {"材料", "鱼"}`——白名单不对：① 材料类 41 项里大量非食物（铁锭/剑刃/船票/藏宝图/水晶等）仍可喂；② 真食物（香草烤兽肉/金锅野猪肋排/战前猛火餐/宠物口粮/长夜暖酒等）type=『消耗品』反被拒。

## 必读文件
- game/commands/social.py pet_feed 白名单段（984-1005）
- game/data/items.py：找 type=消耗品/材料里的『真食物』物品（按名字：烤/肉/餐/口粮/酒/面包/果/蛋/汤/粥/糕点/宴/羹 等），以及材料类里明显非食物的项（铁锭/剑刃/藏宝图/碎片/水晶等）
- game/data/ 里宠物喂养相关设计（24_宠物与伙伴系统.md 对应代码：饱食度机制）

## 任务（精确改动点）
## 方案（数据驱动铁律：标记进数据层，不在引擎硬编码）
1. items.py：给『真食物』物品加 `"food": True` 标记（估计 8-15 个：烤肉/肋排/猛火餐/口粮/暖酒/鱼干/面包/蛋/汤等 type=消耗品的食物 + 若有材料类食物也标）。**鱼保留**（钓鱼产物一直是喂养合法源）。
2. social.py 白名单改：`FOOD_TYPES = {"鱼"}` + 名称路径/序号路径都要求 `d.get("food") or d.get("type") == "鱼"`。即：只能是带 food 标记的物品或鱼。
3. 被拒提示统一：『背包里没有可喂食的食物『XX』！』（原『没有食材』文案可保留或微调，报告里说明）。
4. 注释标『v130.7 意见#22』。
5. **报告必须列出你标记的所有 food 物品清单（中文名+key）**，供主 agent 核对。
