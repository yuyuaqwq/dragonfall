# D2 独特装备子集设计卡（分阶段金字塔）

## 任务
在 D1（特色模板=数值定位）基础上，设计"**独特装备子集**"：一部分装备拥有**独特特殊效果**（如"龙鳞庇护之坠：全元素抗性+15%"），形成金字塔结构——大部分普通（公式+词条），少部分独特（特殊效果），按成长阶段分布，保证结构健康。

## 鱼鱼原话（需求基准）
> "不一定所有都要独特，但是肯定要有一部分独特的"、"依旧是分阶段做，每个玩家的前期中期等等，保证结构健康"

## 现状盘点（已实测）
- **LEGENDARY_EFFECTS（传说专属效果）已存在 58 个**：金钩锋锐(暴击伤害+30%)、处决狂潮(<30%血+80%伤)、龙语印记(叠层增伤)、星陨(AOE)、初火余烬(火伤+灼烧)、时之低语(冷却缩减+8%)、元素共鸣(雷冰+15%)……**触发型机制完整接线**（battle.py `_affix_on_hit`/`_affix_on_taken`）
- **目前只有橙装用**：主名册 208 条中 33 件橙装引用 legendary；74 件 v136 橙装另有引用
- **紫色档 93 件完全没有独特效果**（全公式+词条）
- 名册品质分布：白 11 / 绿 9 / 蓝 62 / 紫 93 / 橙 33（主名册）
- 等级段：0-9 新手(白绿为主)、10-29 前期(蓝)、30-49 中期(蓝紫)、50-69 后期(紫)、70-89 末期(紫橙)、90-100 终局(橙)

## 设计目标
1. **金字塔结构**：大部分装备普通（公式+词条），一部分独特（特殊效果）
2. **分阶段分布**：前期少而简单、中期开始出现、后期/末期丰富、终局最独特
3. **独特感 = 特殊效果**（不是数值偏移模板）：触发型/条件型/机制型效果（AOE/印记/斩杀/反弹/元素增伤/抗性/免疫/偷取/召唤……）
4. **结构健康**：不破坏数值平衡（独特效果不超同品质同级基准太多，或效果有代价/条件），不出现"一件全面碾压"

## 设计要求
1. **设计"独特效果库"扩充方案**：
   - 现有 58 个 LEGENDARY_EFFECTS 基础上，新增约 20-30 个**新独特效果**（覆盖你要的：全元素抗性+15%、受击概率免疫、击杀回血、攻击偷属性、元素亲和、生命偷取、反伤、概率连击、治疗强化、召唤等）
   - 每个效果：key/name/kind/trigger(stat/on_hit/on_taken/turn_start/passive)/effect/desc
   - **参考现有 LEGENDARY_EFFECTS 的格式**（affixes.py:518-665）
2. **设计"独特装备挂载表"**：
   - 从名册中挑选一部分装备挂独特效果（**不全部**）：
     - 橙装：全部挂（现有 58 效果，可补新效果）
     - 紫装：**选一部分**（约 20-30% 紫装挂轻量独特效果，如 50-69 级后期紫装）
     - Boss 掉落装/任务奖励装：**全部挂专属效果**（每个 Boss 一个特色效果，剧情联动）
     - 蓝装/白装/绿装：不挂（保持普通）
   - 每件挂载要说明：装备名 + 效果 + 阶段定位（前期/中期/后期/末期/终局）+ 获得方式（Boss/任务/锻造/掉落）
3. **分阶段节奏设计**：
   - 前期（0-29 级）：**0-1 件**独特装备（教学体验，如新手村奖励一把小独特武器）
   - 中期（30-49 级）：**3-5 件**（主线 Boss 掉落，让玩家第一次体验到"装备有特殊效果"）
   - 后期（50-69 级）：**8-12 件**（区域 Boss/支线任务）
   - 末期（70-89 级）：**15-20 件**（高难副本/隐藏线）
   - 终局（90-100 级）：**10+ 件**（终章任务/最强 Boss，效果最华丽）
   - 总数约 40-50 件独特装备，占名册 208 条约 20-25%（金字塔尖）
4. **数值健康约束**：
   - 独特效果 = 特殊机制，不是纯数值堆叠；**总强度 ≈ 同品质同级基准 + 效果价值**，效果价值应有上限（如等效 ±15% 战斗价值内，参考 D1 §4 模型）
   - 效果强的要有代价/条件（如"全元素抗性+15%"但基础属性-10%，或"攻击偷属性"有概率触发）
   - 不许出现"一件全面碾压另一件"
5. **产出格式**：
   - 独特效果库新增清单（20-30 个，含格式定义）
   - 独特装备挂载表（40-50 件，含阶段/获得方式/效果）
   - 分阶段节奏表（前/中/后/末期/终局各多少件、在哪获得）
   - 3 个完整示例（新手村独特武器 / 中期 Boss 掉落 / 终局传说装备）

## 铁律
- 只设计，不改代码
- 效果格式必须与现有 LEGENDARY_EFFECTS 完全兼容（trigger 类型、effect 字段结构）
- 禁止设计引擎不支持的 trigger（只允许 stat/on_hit/on_taken/turn_start/passive/battle_start——先 grep battle.py 确认支持的 trigger 集合）
