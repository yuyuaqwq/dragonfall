# F2 副本入口设施化 - 命令层落地卡

## 任务
把副本入口"设施化"落地到命令层：消费 F1 加好的 `entry` 字段和 `funcs=["instance"]` 标记，实现"走到入口才能开本"。

## 背景
审计结论（R1/R2）：开本目前是虚空进入（任意位置『副本 <名>』瞬移进本）。策划案有入口位置表。F1（数据层 agent）会给 instances.py 加 `entry: {map, subarea}` 字段、subareas.py 入口子区域加 `funcs=["instance"]`。你负责命令层消费。

## ⚠️ 依赖
F1 可能还在改数据层。**你先读代码确认 F1 是否已完成**（grep instances.py 有没有 `"entry"` 字段、subareas.py 入口子区域有没有 `funcs` 含 `instance`）。如果 F1 未完成：**等/轮询 F1 产出**（最多等 10 分钟，检查数据层落盘），完成后再动手；如果一直没完成，先按"entry 字段存在"的假设写命令层逻辑（用 `C.INSTANCES[kid].get("entry")` 做兼容，没 entry 的副本回退旧行为不卡死）。

## 要做的改动
1. **开本位置校验**（核心）：`game/commands/instance.py` `_instance_start`（L1749 起）在现有校验前/后加：
   - 读 `C.INSTANCES[kid].get("entry")`；若无 entry → 跳过校验（兼容）
   - 有 entry → 校验**队长** `player["cur_map"] == entry["map"]` 且 `player["cur_subarea"] == entry["subarea"]`（或 cur_subarea 是 entry.subarea 的邻居？——**不，严格=入口子区域**，设计见策划案）
   - 不满足 → 提示"📍 请先到【迷雾沼泽·沼泽深处】副本入口处（『前往』）再开本！"，**不扣体力、不开本**
   - 放行规则（参考 R1 兼容红线）：
     - 已通关该副本 → 免位置校验（老玩家便利）
     - 副本 entry 为空 → 免校验（兜底）
     - 队伍里任一人站在入口 → 允许？（设计决策：**队长必须在入口**，简单一致）
2. **副本列表显示入口**：`_instance_list`（L1166-1193）每行加"📍 入口：<map>·<subarea>"（读 entry 字段，有才显示）
3. **入口子区域面板消费**（`game/commands/world.py` 或 base.py）：子区域 funcs 含 `instance` 时，设施面板显示"🏰 此处是【<副本名>】入口（『副本 <名>』进入）"——找消费 funcs 的地方（world.py L2925-3415、base.py L317-425）加 instance 分支
4. **徒步进图接通开本（可选但推荐）**：`world.py` move 命中副本图 + 三档放行后，不再只改 cur_map/cur_subarea，改为：若玩家已在入口子区域 → 提示"🏰 入口已到，队长『副本 <名>』开本"；若直接『前往』副本图 → 保持现状（空转或拦截）
5. **撤退恢复路径**（instance.py L301-355）加同样位置校验？——**不**：撤退恢复是"回到副本深处"，本来就该免位置校验（玩家在副本里撤退，恢复时从入口位置回来）。保持现状。
