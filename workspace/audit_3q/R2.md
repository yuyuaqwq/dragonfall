# R2 副本入口-策划案对照卡

## 任务
对照**策划案**（design 仓库）和**代码**，确认副本入口的"设计意图"和"实际实现"是否一致。

## 背景
鱼鱼问：副本是不是应该做成某些子区域的设施？有个入口，不是虚空进入。
代码现状（初步侦察）：`instance_cmd` 支持『副本 <名字>』直接开本，没看到强制的地图入口要求。

## 具体要查
1. **策划案怎么说**：
   - 在 `C:\Users\yuyu\qqbot\data\plugins\dragonfall\design\new_world\`（独立 git 仓库）找副本/地牢相关章节（如 02 章八·副本总览、地图章节）
   - 策划案里副本是怎么描述的：有没有提到入口/传送门/位置？副本在世界的哪里？
2. **代码对照**：
   - `game/data/instances.py` 每个副本有没有"入口地图/入口子区域"概念？
   - `game/core/maps.py` 的 `map_entry_subarea` 是否有数据支撑（哪些 map 有 entry_subarea）？
   - 玩家进副本前后 cur_map/cur_subarea 怎么变？（instance.py 开本路径）
3. **差距分析**：
   - 设计意图 vs 实际实现：副本是"虚空进入"还是"有入口"？差距多大？
   - 如果要补"入口设施"，策划案里有没有现成的世界观设定可用（比如副本在哪个地图区域）？
