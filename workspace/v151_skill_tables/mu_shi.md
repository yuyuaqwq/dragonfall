## 四、牧师 — 行为「治疗/增益本身」

**形式**：没有资源条。深度来自"这一口奶给谁、这个增益给谁"的行为抉择 + CD 管理。

### 核心机制

```
牧师无资源条。
深度 = 行为选择 + CD 管理 + 治疗耐受：
  治疗耐受：连续治疗同一目标，效果每层递减20%（第3口起减半）
  逼牧师轮换目标，不能无脑盯一个奶
```

**决策问句**：这一口奶给谁？增益给谁？驱散谁？

**会咬人的代价**：治疗耐受（连续奶同一目标越来越没效）。
