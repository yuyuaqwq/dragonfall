## 六、拳师 — 挂账「破绽」

**形式**：破绽条挂在**敌人身上**，不占拳师自己资源位。推满 → 敌人跳回合。

### 核心机制

```
破绽条 0-50（挂敌人身上，全队共享，非拳师私有资源）
  技能命中推条，每回合自然衰减4
  推满 → 敌人【破绽】：跳过下回合行动（CTB下=白损失一整次行动）
  阈值 ×1.35 递增（封顶×2.5）：越打越难推满，触发越来越痛
  换目标 → 阈值重置但进度清零
```

**决策问句**：专打一个，还是换目标重开？

**会咬人的代价**：拳师自身零生存手段（全游最高风险前排）。
