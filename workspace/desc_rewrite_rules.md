# 技能 desc 重写规范（奥兰迪亚·余烬纪年）

## 目标
把 skills.py 里所有技能 desc 从「技能名！数值(机制)」的直白复读，改写成**有西幻味道的设定文案 + 保留全部机制数值**。

## 示例
### 旧（要改掉的风格）
- `"基础斩击，100% 物理伤害。先手(速度高于目标)时伤害＋15%"`
- `"火球术！火系 100% 伤害，挂 1 层火印。已有火印时＋20% 且层数＋1(燎原)"`
- `"蓄力斩！蓄力 1 回合，期间受击会被打断；蓄力完成挥出 220% 破防一击。"`
- `"战吼！攻＋30% 3 回合。组队时全队攻＋30%(团队技能)"`

### 新（要有味道）
- `"挥剑如风，趁敌未稳先发制人——造成 100% 物理伤害；若你的速度高于目标，剑势更盛(伤害＋15%)"`
- `"将游离的火元素凝成灼热弹丸掷出，命中即焚(100% 火系伤害)并烙下火印；若目标已带火印，火焰燎原引爆(伤害＋20%、火印层数＋1)"`
- `"屏息凝神，把全身力量沉入剑锋——蓄力 1 回合(受击会打断)，下一击撕裂空气，造成 220% 破防伤害"`
- `"胸腔炸开一声战吼，怒火点燃血液——攻击＋30% 持续 3 回合；组队时战意传染全队(全队攻＋30%)"`

## 铁律（必须遵守）
1. **保留全部机制数值**：所有百分比(%)、回合数、乘数(×)、叠层数、概率、CD、消耗 必须原样保留（数字不能改、不能丢）
2. **去掉「技能名！」复读**：不在开头复读技能名+感叹号，用设定文案开场
3. **机制信息完整**：玩家要能从 desc 看懂这个技能干嘛的（伤害/治疗/增益/控制/条件触发）
4. **西幻风味**：魔力、元素、剑刃、战意、元素之力等奥兰迪亚世界观词汇；不要武侠/佛教/现代词汇
5. **直白不堆砌**：一句话讲清设定，别写成长篇小作文；30-60 字为宜
6. **禁止引入这些词**（测试断言会失败）：`18%`（特定技能）、`破势`、`引爆`（特定技能）、`满印`、`潜行持续`、`满力龙威真伤态`
   - 例外：如果技能机制本身是"引爆火印"（如火球术燎原），可以用"燎原""点燃""迸发"等替代"引爆"
7. **被动技能**：desc 要说明触发条件和效果（如"生命低于 50% 时攻击＋10%"），设定文案点缀但不丢机制

## 输出格式
只输出一个 JSON（不要其他解释）：
```json
{
  "技能key": {"name": "技能中文名", "new_desc": "新描述文本"},
  ...
}
```
- 技能 key 用原文（如 sk_hui_kan）
- 必须覆盖你负责的所有技能，一个不漏
