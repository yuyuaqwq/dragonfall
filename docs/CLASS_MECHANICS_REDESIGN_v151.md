# 奥兰迪亚·余烬纪年 — 职业机制重构 v151（打碎资源条）

> 承接上轮结论：旧体系真正的病是「12 个职业 = 12 条私有资源条 + 12 套攒点→放大循环」。
> v151 的硬约束只有一条：**每个职业先回答「我的机制是什么形式」，再谈技能。**
> 机制形式必须彼此不同。没有一个职业是「0→N 攒满 → 消耗 → 归零」的资源条。
>
> 战斗是 CTB（速度 = 行动频率，`ct = 100/min(spd,80)`）。所有机制最终都落到「怎么改变行动频率」上。

---

## 〇、六职业 · 六种机制形式

| 职业 | 机制形式 | 一句话 | 是不是资源条 |
| --- | --- | --- | --- |
| 🛡️ 战士 | **叠层状态** | 战意叠在身上，持有即强，可主动兑现 | ❌ 不消耗、不归零 |
| 🔥 法师 | **挂账** | 元素印记铺在敌人身上，铺满引爆 | ❌ 不占自己位 |
| 🏹 游侠 | **预算** | 精力自然回，花多少、花在哪 | ⚠️ 唯一保留的条，但非攒满放 |
| ✨ 牧师 | **行为** | 治疗/增益本身就是机制，无资源条 | ❌ 根本没有条 |
| 🗡️ 刺客 | **计数** | 连段命中递增，断连归零 | ❌ 是计数不是货币 |
| 🥊 拳师 | **挂账** | 破绽条挂在敌人身上，推满跳回合 | ❌ 不占自己位 |

**自检**：六种形式 = 叠层 / 挂账 / 预算 / 行为 / 计数 / 挂账，五种类型、无一句重复、**零资源条**。

## 一、战士 —— 叠层状态「战意」

**形式**：状态层。战意是叠在身上的 buff 层数，**持有即生效，从不被消耗**，技能根据战意层数改变形态。

### 核心机制

```
战意（0-10 层，叠在身上，不是资源条）
  获取：普攻/技能命中 +1 层，击杀 +2 层
  持有收益：每层 攻击 +4%（满 10 层 +40%）
  持有代价：每层 自身受伤 +2%（满 10 层 +20%）   ← 越强越脆
  满 10 层 → 免费进【狂暴】形态（不消耗战意）：
      形态内 普攻双段 2×70% + 吸血 25%
      但每回合自动 -2 层战意，跌破 4 层退出
  主动兑现：【冷静】花 5 层战意 → 回 20% 生命 + 清一个减益
```

**为什么不是资源条**：没有"扣战意放技能"这个动作。战意是**当前状态**，玩家权衡的是"堆高变强但变脆" vs "兑现换生存"——这是持有型的持续抉择，不是攒满就放。

**会咬人的代价**：战意越高压越脆。想打痛，就得把自己置于被秒的风险里。

**决策问句**（战前预案）：`战意策略` = 狂堆（满10硬扛）/ 平衡（≥6 就冷静一次）/ 稳健（≤4 就兑现）

| 基础 | 破甲斩 | 破防 | 每层战意 +X% 破防效率 |
| 基础 | 战吼 | 全队攻击 +30% | 自身 +2 战意 |
| T1 | 裂地斩 | 破防斩击 | **战意 ≥6 时附加流血** |
| T1 | 怒斩 | 高伤斩击 | 每层战意 +X% 伤害（持有收益兑现） |

## 二、法师 —— 挂账「元素印记」

**形式**：挂账。印记铺在**敌人身上**，不占法师自己的资源位。蓝条保留（纯蓝施法是身份铁律）。

### 核心机制

```
元素印记（火/冰/雷，各 0-3 层，铺在单个敌人身上）
  铺印：火球术→火印 / 冰锥→冰印 / 雷击→雷印
  引爆反应表（铺满或主动引爆时结算）：
      火印 + 冰  = 蒸发  伤害 ×1.30
      雷印 + 火  = 超载  全体 AOE
      冰印 + 雷  = 冻结  目标跳过 1 次行动
      雷印 + 雷  = 感电  连击 +1（印记保留）
```

**为什么不是资源条**：印记是敌人身上的状态，不占法师自己的资源位。法师没有"充能条"，决策是"给谁铺、铺哪系、铺几层再引爆"——挂账型的经典博弈。

**会咬人的代价**：站桩读条（重出手 1.3），架设态受击 +20%、不能普攻。想爆发就得把自己钉在原地挨打。

**决策问句**：`铺印策略` = 专攻一个（印记叠满引爆）/ 铺开多目标 / 只挂不爆（等队友触发反应）

| 基础 | 雷击 | 100% 魔法 | 挂雷印 1 层 |
| T1 | 双系连珠 | 两段双系伤害 | 挂两系各 1 层 |

## 三、游侠 —— 预算「精力」+ 挂账「标记」

**形式**：预算（精力自然回）+ 挂账（标记在敌人身上）。这是全职业唯一保留"条"的，但它是**预算型**——永远有箭，花多少在哪，不是攒满放。

### 核心机制

```
精力（0-100，每回合自然回 30）—— 预算，不是资源
  三档预算：连射档 ≤20 / 压制档 25-40 / 终结档 50-100
  满 100 → 凝神屏息（强制归 0，下回合低耗档段数 +1）

标记（叠层 0-3，铺在敌人身上）—— 挂账
  全队对标记目标增伤，叠满 +30%
```

**为什么不是资源条**：精力是"每回合恒定收入、花光才不浪费"的预算制，没有"攒满"这回事（满了反而被强制排气）。标记是铺在敌人身上的，不占自己位。

**会咬人的代价**：身板脆（后排），且满精力会强制排气——手牌多的时候被迫打掉，算时机是代价。

**决策问句**：`精力分配`（连射/压制/终结档）+ `标记目标`（主目标/最高HP/最低HP斩杀）

## 四、牧师 —— 行为「治疗/增益本身」

**形式**：行为。治疗/增益/净化**本身就是机制**，没有资源条。牧师的深度来自"行为选择"，不是"攒资源"。

### 核心机制

```
牧师没有资源条。
深度来自「这一口奶给谁、这个增益给谁」的行为抉择：
  单体大奶 / 群体小奶 / 预防盾 / 驱散 / 增益 / 复活
  每个行为有独立 CD，逼玩家排优先级
```

**会咬人的代价**：**治疗耐受**——连续治疗同一目标，效果每层递减 20%（第 3 口起减半）。逼牧师轮换目标，不能无脑盯一个奶。这是"分诊"决策。

**决策问句**（战前预案）：`治疗优先级` = 残血优先 / 主C优先 / 前排优先 / 预防盾优先

## 五、刺客 —— 计数「连段」

**形式**：计数。连段是**命中计数**，连续命中递增，miss/被闪避就断。不是资源条。

### 核心机制

```
连段（0-10，命中计数，不是资源）
  命中 +1 段，未命中（miss/闪避）→ 归零
  每段：暴击率 +3%（10 段 +30%）
  终结技伤害随连段线性增长（每段 +10%）
```

**为什么不是资源条**：连段是"当前连击状态"，涨靠命中、断靠失误。没有"攒满放"，只有"冒险续连 vs 见好就收打终结"。

**会咬人的代价**：断连归零——高风险高回报。被闪避一次，之前的连段全部白费。

**决策问句**（战前预案）：`终结时机` = 快刀（连段≥3 就打终结）/ 满段（连段=10 才打）/ 残血斩杀

## 六、拳师 —— 挂账「破绽」

**形式**：挂账。破绽条挂在**敌人身上**，不占拳师自己的资源位。推满 → 敌人跳过回合。

### 核心机制

```
破绽条（0-50，挂在敌人身上，不是拳师的资源）
  技能命中推条，每回合自然衰减 4
  推满 → 敌人【破绽】：跳过下回合行动（CTB 下 = 白损失一整次行动）
  阈值 ×1.35 递增（封顶 ×2.5）—— 越打越难推满，但触发越来越痛
  换目标 → 阈值重置但进度清零
```

**为什么不是资源条**：破绽是敌人身上的状态，全队可见、全队受益。拳师的决策是"专打一个还是换目标重开"——挂账型的经典博弈。

**会咬人的代价**：拳师自身零生存手段（全游最高风险前排）。没有减伤、没有回复，用高血防成长硬扛。

**决策问句**（战前预案）：`破绽目标` = 专打主目标 / 阈值超 ×2 就换目标

## 八、CTB 主轴（贯穿六职业）

六种形式最终都落到「改变行动频率」这个 CTB 唯一的硬通货上：

- **战士**：狂暴形态普攻双段 = 出手次数翻倍
- **法师**：冻结反应 = 目标跳过行动；重出手 = 自己让出频率换单发质量
- **游侠**：蓄力 = 花多次出手换一发重箭；凝神屏息 = 频率节流
- **牧师**：安眠曲 = 让敌人少动；治疗耐受 = 逼行为轮换
- **刺客**：连段 = 多动多命中多暴击，正反馈
- **拳师**：破绽推满 = 敌人白损失一整次行动（CTB 下顶级控制）

## 九、待拍板

1. **六职业够不够**：隐藏六职业的机制（真伤轴/时停/召唤/点名/影舞态/撼岳）已经拆进上面六职业的技能骨架里了，不再作为独立职业。这个口径 OK 吗？
2. **游侠是唯一保留"条"的**：精力预算制是我认为唯一该保留的"条"（它本来就是真资源管理）。要不要也把精力改成别的形式，还是保留预算？
3. **牧师"无资源条"**：删掉信仰值后，牧师强度靠 CD 管理和治疗耐受博弈。这个方向你能接受吗？（可能比有资源条的牧师"看起来弱"，因为少了"攒满放大"的爽点）
