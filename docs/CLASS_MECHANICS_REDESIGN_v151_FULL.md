### 0.4 出手节奏（CTB 独有，职业身份）[引擎新增挂点 ct_cost_mult]

CTB 下"出手快慢"是核心决策：出手后多久轮到自己。这是**职业身份**，不是硬枷锁——每条线保留 1~2 个异型节奏技能作"变奏"。

```
ct_cost_mult（技能行动成本系数，缺省 1.0）：
  快技 quick 0.7 → 出手后更快轮到自己，base 压低 ~15%
  标准       1.0
  重技 heavy 1.3 → 出手后更慢轮到自己，base 抬高 ~20%
```

| 节奏型 | ct_cost_mult | 职业         | 理由             |
| --- | ------------ | ---------- | -------------- |
| 疾速  | 0.7 为主       | 刺客、游侠      | 多动滚雪球 / 铺标记    |
| 标准  | 1.0 为主       | 战士、牧师、吟游诗人 | 稳；诗人换歌是 0.7 快技 |
| 沉重  | 1.3 为主       | 法师、拳师      | 站桩读条 / 蓄力重拳    |

> 落地：`_ct_cost(spd)` 乘技能 `ct_cost_mult`，纯数据字段，`battle.py` 加一行，零职业特判。

### 0.5 数值口径（对齐 review，杜绝虚标）

```
dmg = atk × power × pmult
pmult = skill_power_mult(lv)   # 每级+10%，满级(Lv.5)×1.40
      × 冻结×潜行×叠层×条件×魔法×被动×反应×词缀×元素×种族×形态
      → clamp 6.0
暴击/暴伤/幸运 = 独立乘区
```

- 本表 `base` = **Lv.1 裸倍率**（唯一真值源）。`满级eq` = base × 1.40 × 条件（参考值，由 `calc_eq.py` 生成，禁止手写进 desc）。
- 天花板：T1 单发 eq ≤ 2.5 / T2 ≤ 3.5 / T3 ≤ 4.5。
- 真伤 ×0.8 计入 eq，每线真伤 ≤ 2 个（签名）。AOE≥3 ×0.6。多段总倍率 ≤ 同档单体 ×1.15。
- 控制递减：同目标 3 回合内 100%→50%→免疫；首领固定 1 回合。

## 一、战士 — 叠层状态「战意」

**形式**：战意是叠在身上的 buff 层数，**持有即生效，从不消耗**。

### 核心机制

```
战意 0-10 层（叠层，不是资源条）
  获取：普攻/技能命中 +1 层，击杀 +2 层
  持有收益：每层 攻击 +4%（满10层 +40%）
  持有代价：每层 受伤 +2%（满10层 +20%）   ← 越强越脆
  满10层 → 免费进【狂暴】：普攻双段2×70% + 吸血25%，每回合-2层，跌破4层退出
  主动兑现：【冷静】花5层战意 → 回20%生命 + 清1个减益
```

**关键**：没有"扣战意放技能"。技能是"战意越高效果越强"，或"触发形态变化"。

**决策问句**：战意堆多高？狂堆（硬扛）还是兑现（换生存）？

## 二、法师 — 挂账「元素印记」

**形式**：印记铺在**敌人身上**，不占法师自己资源位。蓝条保留（纯蓝是身份）。

### 核心机制

```
元素印记（火/冰/雷，各0-3层，铺在单个敌人身上）
  铺印：火球术→火印 / 冰锥→冰印 / 雷击→雷印
  反应表（主动引爆或铺满时结算）：
      火印+冰 = 蒸发 ×1.30
      雷印+火 = 超载 全体AOE
      冰印+雷 = 冻结 目标跳过1次行动
      雷印+雷 = 感电 连击+1（印记保留）
```

**决策问句**：给谁铺、铺哪系、铺几层再引爆？

**会咬人的代价**：站桩读条（重出手 1.3），架设态受击+20%、不能普攻。

## 九、元素属性与抗性体系（七职业的底层规则）

> 现状诊断：代码里已有元素属性（`element`: fire/ice/thunder/dark）+ 元素反应 + 抗性概念（`elem_res`/`abyss_res`/`dot_res`/`immune_dots`/`adapt`），但**怪物侧没配数据**——火焰怪没有火抗、免疫列表全空，导致"火/冰/雷"只是三个图标，没有实质克制。这一章把底座补齐。

### 9.1 元素属性（伤害的"属性轴"）

| 属性 | 对应 DOT | 克制 | 被克 | 现有挂载 |
| --- | --- | --- | --- | --- |
| 火 fire | 灼烧 burn | 克冰（对冰冻目标+25%伤害，解冻） | 被雷克 | 元素印记·火印 / 血怒灼烧 |
| 冰 ice | 冻结 freeze | 克雷（对雷印目标+25%，打断） | 被火克 | 元素印记·冰印 / 桎梏冻结 |
| 雷 thunder | 感电 | 克火（对灼烧目标+25%） | 被冰克 | 元素印记·雷印 / 桎梏麻痹 |
| 暗 dark | 腐蚀 corros | 无克制，专打高防（真伤轴） | 无 | 毒刃腐蚀真伤 |

**克制规则**（三角循环，简单可记）：火→冰→雷→火。克制命中时伤害 ×1.25，且触发一次对应反应（蒸发/超载/感电）。

> 这条让"铺哪系印记"有了真实决策：看到火焰怪，就该铺冰；看到冰霜怪，就该铺火。否则三色印记是换皮。

### 9.2 抗性（伤害的"减免轴"）

| 抗性 | 减免对象 | 上限 | 现状 |
| --- | --- | --- | --- |
| `elem_res` 元素抗性 | 火/冰/雷 三系魔法伤害 | 50% | 玩家有，怪物无 |
| `abyss_res` 深渊抗性 | 暗系伤害 | 50% | 玩家有，怪物无 |
| `dot_res` DOT 抗性 | 毒/灼烧/流血/腐蚀 | — | 怪物无 |
| `immune_dots` 免疫列表 | 指定 DOT 类型直接免疫 | — | 怪物无 |
| `adapt` 适应耐受 | 连续叠层后 DOT 耐受递增 | 95% | 机制在跑，缺基础值 |

**要补的**：怪物数据补 `elem_res` / `dot_res` / `immune_dots` 三个字段。设计意图：

- **火焰怪**：`elem_res` 火 0.5、冰 0（高火抗低冰抗）→ 逼玩家换系。
- **免疫怪**：`immune_dots: ["burn"]` 免疫灼烧 → 血怒线的"内燃"（火免转真伤）才有意义，否则这个机制白设计。
- **高防 Boss**：`immune_dots: ["poison"]` 免疫毒 → 毒刃线的"腐蚀真伤轴"才是唯一解，否则 DOT 无脑叠。

### 9.3 DOT 结算（毒/灼烧/流血/腐蚀）

沿用 `battle_config.py` 的 `DOT_DEFS` + `_tick_dots` 混合公式：

```
每层每回合伤害 = (atk×a + matk×m + max_hp×h) × 层数 × mult × (1 - 总抗)
总抗 = min(0.95, dot_res + adapt)   # 连续叠层 adapt 递增，2 回合没叠 -4% 消退
immune_dots 命中 → 直接移除不结算
corros（腐蚀）→ true_dmg 分支，绕过 def/mdef（但不豁免目标异常抗性）
```

**这套已有的 DOT 体系，加上 §9.2 补的怪物 `dot_res`/`immune_dots`，毒刃线（毒）、血怒线（灼烧）、游侠林语（毒）才有"打不动的场景"可博弈。**

### 9.4 元素召唤（下放给元素法师）

元素法师 T2/T3 可召唤元素生物（火/冰/雷元素），进召唤物表：

| 召唤物 | 来源 | HP | ATK | 行动 | 吃AOE | 上限 |
| --- | --- | --- | --- | --- | --- | --- |
| 火元素 | 元素法师·唤火 | 主人 max_hp×0.40 | 主人 matk×0.50 | 每回合对目标喷火（挂火印1层） | 是 | 1 |
| 冰元素 | 元素法师·唤冰 | 主人 max_hp×0.40 | 主人 matk×0.40 | 每回合冰锥（挂冰印1层+减速） | 是 | 1 |
| 雷元素 | 元素法师·唤雷 | 主人 max_hp×0.40 | 主人 matk×0.45 | 每回合雷击（挂雷印1层） | 是 | 1 |

> 召唤 = "印记的进阶用法"：火印招火元素，元素生物替法师自动铺印，让法师腾出手引爆。这样元素线"爆发 + 召唤"两种玩法，元素生物的攻击也带元素属性、吃 §9.1 克制、吃 §9.2 抗性——整条属性轴闭环。
