## 二、职业树总览

```
6 根基（注册时可选）
  └─ Lv.30 一转（EVOLVE_LEVELS[1]）
       ├─ 攻线（path=1）  e.g. 狂战士
       ├─ 守线（path=2）  e.g. 盾卫士
       └─ ★ 隐藏线（试炼解锁后可选，单分支 path=1）
            ├─ Lv.40+（v107：T1=40 T2=60 T3=90）
            ├─ Lv.30+（吟游诗人：T1=30 T2=60 T3=90）
            └─ Lv.60+（魔剑士：T1=60 T2=75 T3=90 特色档位）
  └─ Lv.60 二转 / Lv.90 三转：当前线深化（常规分支或隐藏线各自 T2/T3）
```

- 等级门槛统一 `EVOLVE_LEVELS = {1:30, 2:60, 3:90}`；魔剑士 T2 用 75（evolve 数组既有设计）
- 隐藏线 = 根基职业上的第三分支线：30 级一转可见但锁定（提示试炼），试炼解锁后随时可选
- 已解锁 + 等级达标 → 转职进入隐藏线对应档位（见 §4 修为继承）

映射原则：
1. **机制契合**（龙血=坦克→战士、影武=暴击刺客→刺客、苦修士=连击拳→拳师）

3. **近义名 = 血缘暗示**（奥术师↔法师守线"秘法法师"、影武者↔刺客攻线"影舞者"——近义不是 bug 是设计，暗示同源）

## 四、修为继承规则（核心机制）

转隐藏职业时，**tier 按当前等级继承**，不再重置 0：

```
继承 tier = 满足 level >= 门槛 的最高档位
  v107 隐藏：  T1=40  T2=60  T3=90
  吟游诗人：  T1=30  T2=60  T3=90
  魔剑士：    T1=60  T2=75  T3=90
```

- 例：60 级战士转龙血战士 = **龙裔斗士（T2）**；90 级转 = **龙魂战将（T3）**；40 级转 = 龙血战士（T1）
- `evolve_path` 统一 = 1（隐藏线单分支）
- **技能继承**：转职给该职业 PLAYER_SKILLS 中 `lv <= 当前等级` 的全部技能（60 级转 = 60 级技能全给，身份匹配）
- 效果：练得越深觉醒越强，基础分支不白练，60 级转职不再是从头再来

## 六、隐藏线转职命令（统一路由）

1. **『转职 <档位名>』**：`_V107_HIDDEN_MAP` 扩展为**全部档位名**（T1/T2/T3 共 39 个名字 + 别名），统一路由 `_evolve_hidden_generic`
   - 校验：① unlock 已解锁 ② 等级 >= 目标档门槛 ③ 当前 tier == 目标-1
   - 吟游诗人/魔剑士 T2/T3（灵魂歌者/黎明颂者/符文骑士/咒刃领主）同样入表
2. **『转职』（无参数）**：
   - 隐藏职业玩家 → 显示下一阶信息（"下一阶：奥法大师 Lv.60，『转职 奥法大师』传承"）或已满
   - 基础职业玩家 → 现状不变（引导找导师）
3. 基础职业三档：导师对话转职不变（v95.23 机制保留）

## 七、转职重置（反悔通道）

- 基础职业玩家：现状不变（付费回基础职业）
- **隐藏职业玩家：『转职重置』= 回到渊源根基职业**（class_name → src_base，tier=0，evolve_path=0，清隐藏线技能），付费，可重新选线
- 渊源 = classes.py 新增 `src_base` 字段（全系隐藏职业回退默认值：战士）
