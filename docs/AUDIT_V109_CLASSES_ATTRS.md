## 二、P1（明显缺陷）

### P1-1 占星者核心机制「运势」未实装（设计承诺缺失）
- 设计（v107 §4.3）：幸运转化为暴击补充 + 暴击 30% 概率追加 50% 伤害。实现：luck 在 battle.py **零消费**（全代码仅面板/词条/掉落端 combat.py:1566/1675），占星者实际用游侠风行者 wind 机制顶替（星陨 mech=wind），与设计「星陨=暴击强化」不符。
- **建议**：二选一——实装 luck→暴击联动（暴击时 30% 追加 50%），或把 luck 专属改为 wind 系并改文档。

### P1-2 武圣专属「连击强化 0.30→0.50」未落地
- 设计（v107 §4.3）：combo 三连追加 0.30→0.50。实现：battle.py:1782 三连追加仍 0.30；0.45 的 combo_boost 是拳师分支被动「连招精通」（skills.py:1021），武圣技能表没有 combo_boost。
- **建议**：武圣技能组补 combo_boost 被动，或将 0.45 提到 0.50。

### P1-3 数值哲学矛盾三层成立（策划案 vs 设计文档 vs 实现）
- 策划案 09 章 L679：「隐藏职业 ≠ 数值碾压，特色在机制，**输出低于主流职业**」；v107 设计文档 §5.3：「base 比同系基础职业**高 8-12%**」——两文档逻辑互斥。
- 实测（裸装 Lv.40/60/90 面板加权，与鱼鱼数据逐项一致）：9/13 隐藏职业面板为正，7 个 ≥+5.8%：

| 档位 | 职业 | 强度差 | | 档位 | 职业 | 强度差 |
|---|---|---|---|---|---|---|
| 超上限 | 魔剑 | **+13.3%** | | 8-12% 区间 | 龙血/影武/亡灵/丛林 | +8.2~+10.0% |
| 低于下限 | 奥术/血法/虚空/占星/武圣 | +5.8~+7.0% | | 持平/负 | 兽王 ±0 / 圣殿 -7.7 / 吟游 -19.6% | |

- 机制叠乘放大：亡灵骷髅海 3×66%=198% atk/回合无消耗自动输出；兽王影狼 130% 真伤/回合；影武 DPS 粗模刺客 130-171%；血法 Lv.40 单发 195%；龙息之怒 power 0.9 超 §5.1「0.6-0.8」上限；魔剑「不是数值碾压」却是数值最碾。
- 反向：圣殿对战士 -7.7%（Lv.40 输出粗模仅战士 31%——坦克定位可解释，但解锁成本 Lv.40 任务链 vs 战士守线免费，收益为负）；虚空输出粗模 67-86%（技能 power 全线偏低）。
- **建议**：见 §六平衡调整表，需鱼鱼拍板方向。

### P1-4 圣殿骑士归属：v107 文档(牧师线) vs v108 代码(战士线) 矛盾
- v107 文档 HIDDEN_CLASSES_V107_DESIGN.md §4.1/4.2/4.3（行 144/152/189）写「圣殿骑士|牧师|坦克辅助」；v108 classes.py:483 `src_base="cls_zhan_shi"`。
- 机制核实：圣殿机制=护盾/格挡/格挡反击/圣光审判——**100% 属于战士坦克线**（牧师全系无盾无格挡），v108 战士线机制正确、名谱正确（盾卫士→圣殿骑士是 stage7 既有升级链）。v107 写牧师线是「主题(圣光)+覆盖平衡」驱动。
- 次生问题：① 战士守线 T1 盾卫士分支**技能名「圣光壁垒」残留**（skills.py:1256-1265）与圣殿骑士 T3 档位名跨命名空间同名；② 牧师攻线 T1「圣武士」与战士隐藏 T1「圣殿骑士」同原型跨根分裂。
- **建议**：文档同步（v107 文档 4 处过时归属：圣殿→战士、虚空→法师、吟游→牧师、魔剑→战士）；盾卫士技能「圣光壁垒」→「坚盾壁垒」。

### P1-5 面板 13 个 0 值属性仍显示（v106.4「0 不显示」未推广）
- player.py:817 只认 OPTIONAL_STATS 9 个；实测 40 级空装战士面板输出 **13 行 0 值**（物穿/法穿/固定物穿/固定法穿/韧性/幸运/冷却/深渊抗/经验加成/金币加成/治疗强度…）。
- **建议**：0 值隐藏推广到全部 stat_rows（或扩展 OPTIONAL_STATS 至 PCT_STATS 全量）。

### P1-6 pierce 魔法技能失效（结算链与数据声明不一致）
- 圣殿骑士「审判之剑」（skills.py，kind=魔法 power1.8 pierce:True）→ battle.py:1676 仅 `kind=="物理"` 分支消费 pierce，魔法分支忽略 → pierce 静默失效，吃 mdef 公式，技能实际弱于设计。
- 同类：毒 dot（battle.py:2259）/灼烧 dot（2245）/元素反应超载（1641）/灼烧引爆（1445）均直扣 `_damage_enemy` 不消费魔免/元素抗——PVE 无感（怪无对应属性），PVP 高于设计。

### P1-7 pierce 与真伤三档退化
- engine.py:696 pierce 与 true 同分支（都是 atk 直伤）；`_damage_enemy` 无免伤消费点 → 玩家输出方向 pierce 与真伤**完全等价**，「无视防御吃免伤」中间档语义未落地。
- 隐患：`_damage_player`（battle.py:2553）无 dmg_type 参数，未来新增怪物真伤会被格挡/被动减伤/词条减伤/金身削减，违反「真伤绕过全部减伤」设计 §10.1。

## 四、P3（建议/文案）

1. 真伤 power 0.9（龙息之怒 lv75）超设计 0.6-0.8 上限 → 0.8。
2. `true_dmg` 字段零使用（skills.py:3078 注释声明，结算按 kind=="真伤"）→ 按文档补或删注释。
3. 词条附加伤害无 dmg_type 透传（数值级等效跟随 ✓，未来敌方类型减免则失效）。
4. 普攻附魔段（设计「魔剑士附魔普攻→magi」）在 _player_attack 无 magic_add 消费点。
5. PVP 输出方向敌方玩家快照的 block/phys_reduce/magic_reduce/elem_res 全部不消费（穿透/真伤 PVP 差异消失）。
6. 转职回执兜底文案「进阶技能请找导师学习」实际不可达（隐藏线无导师）。
7. 血缘拒绝文案对同源隐藏玩家（魔剑→龙血）说「先以战士的身份历练」误导。
8. 别名转职强制 tier=1（90 级『转职 龙血』只得 T1 需再转 2 次）→ 别名按等级继承档位。
9. 『转职重置』回执「『转职 <隐藏职业>』」字面占位符未填充（player.py:945）。
10. engine.py:188 注释声称 dual_stat「由 battle.py 结算」但 battle.py:923-929 无该分支——注释误导。
11. abyss_res/heal_power/shield_power 被动注册冗余（_PASSIVE_STAT_APPLY 有注册但 skills.py 无对应被动技能）。
12. pene_flat/pene_mflat 游离属性体系白名单外（constants.py 无 PCT/OPTIONAL 条目）→ 补进 constants 并进 0 隐藏白名单。
13. 斩杀线「随技能等级提升」（设计 §4.3）未实现（cond_hp 常量 0.30；鱼鱼提示 35%——代码/设计文档均 30%，以 30% 为准）。
