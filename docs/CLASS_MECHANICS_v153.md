## 〇、总纲

### 0.1 时间轴：唯一模型（对齐 v152 引擎现状）

```
全局绝对时刻 _now（单位：刻，浮点，单调递增）

单位下次可行动绝对时刻：
    next_act_at = now + cost + cast

    cost = BASE_DELAY / min(spd, SPD_CT_CAP)   # 恢复等待 = 40 / min(spd, 80)
    cast = 技能固有动作耗时（刻，数据驱动，不随速度变）

速度只影响「恢复等待」，不影响「动作本身耗时」。
```

**标定常数（读 `battle.py`）**：

| 常数            | 值    | 含义                                |
| ------------- | ---- | --------------------------------- |
| `BASE_DELAY`  | 40.0 | 行动间隔基数（v152 标定：普通怪战斗 ≈ 49 刻）      |
| `SPD_CT_CAP`  | 80.0 | 参与 ct 计算的速度软上限                    |
| `ACT_TICK`    | 1.0  | 1 刻 = 1 游戏秒（引擎内部时刻以秒存储；玩家侧只显示「刻」） |
| `CAST_ATK`    | 1.0  | 普攻默认动作耗时                          |
| `CAST_SKILL`  | 1.6  | 技能默认动作耗时（未配 `cast` 字段时兜底）         |
| `CAST_DEFEND` | 0.6  | 防御默认                              |
| `CAST_FLEE`   | 2.0  | 逃跑默认                              |

**一场战斗的尺度**：约 49 刻。基准角色（spd 50 → cost 0.8）用一次标准技能 ≈ 0.8 + 1.6 = 2.4 刻
  
→ **一场战斗玩家约出手 20 次**。所有"持续时间 / CD / 衰减速率"都按这个尺度标定。

### 0.2 时间单位：「刻」，不是「秒」，更不是「回合」

- **设计单位一律用「刻」**（1 刻 = 1 秒，引擎内部绝对时刻以秒存储）。
    
  技能描述、战报、持续时长**只写「刻」，不写「秒」**——写「秒」会让玩家把游戏时长
    
  和现实时间、和 QQ 聊天的节奏挂钩，产生误解；「刻」是游戏内的时间单位，玩家不用换算。
- 「刻」是**时间单位**（持续多久），「回合」是**行动计数**（数几次行动）——「回合」已死，全文禁用。
- 「行动次数」只在事件语义下使用（CD = 用一次要歇几次出手），并换算成刻写进表。

| 效果类型                      | 计时单位          | 写法             |
| ------------------------- | ------------- | -------------- |
| buff / debuff / 护盾 / 持续回血 | 刻             | `持续 8 刻`       |
| 技能 CD                     | 刻             | `CD 12 刻`      |
| 持续伤害（DOT）                 | 每 1 刻跳一次      | `毒 2 层，持续 8 刻` |
| 控制（眩晕/冻结/睡眠）              | 刻             | `定身 2.5 刻`     |
| 挂账类（印记 / 猎印 / 破绽）         | 每刻衰减          | `每刻 −1.7`        |
| 计数类（连段 / 战意）              | 事件（命中/受击），无时间 | —              |

### 0.3 出手速度 = 职业身份（新增的第一设计轴）

v152 用 `ct_cost_mult`（0.7 / 1.0 / 1.3）乘在 cost 上——**这个字段已被引擎废弃**。
  
新引擎里每个技能自带 `cast`（刻），出手速度因此成了**比 spd 更直接、更可控的职业轴**。

**为什么 cast 比 spd 更重要**：spd 只调 cost（0.5–2.0 刻 区间），而 cast 是硬叠加的。
  
一个 cast 3.0 刻 的重技，spd 从 20 拉到 80（4 倍）也只把循环从 5.0 刻 压到 3.5 刻（1.43 倍）
  
——**固定的 cast 是速度收益的稀释器**。所以「谁的手快」由 cast 决定，不由 spd 决定。

| 职业   | cast 主区间        | 节奏型    | 身份                         |
| ---- | --------------- | ------ | -------------------------- |
| 刺客   | 0.5 – 1.0       | **疾速** | 短前摇高频，靠次数与连段滚雪球            |
| 游侠   | 0.6 – 1.3       | **轻快** | 起手快，蓄力技拉长                  |
| 拳师   | 0.7 – 1.5       | **连打** | 段数多、单段快                    |
| 战士   | 0.9 – 2.0       | **中速** | 稳，重技偏慢                     |
| 牧师   | 0.9 – 1.8       | **中速** | 治疗快、大招慢                    |
| 法师   | 1.0 – 2.6       | **分裂** | 元素读条换爆发；奥术力场/反制快出手、倾泻读条     |
| 吟游诗人 | 0.6 / 1.2 / 2.4 | **变奏** | 起手 / 吟唱 / 终章三档——节奏切换就是形式本身 |

### 0.4 平衡口径：eps（每刻等效倍率）

**这是 v153 唯一的强度口径，取代 v152 的单发总eq 天花板。**

```
基准 spd = 50  →  cost = 40 / 50 = 0.8 刻

cyc  = 0.8 + cast                    # 基准循环时间（刻）
总eq = base × 1.40 × hits × (0.8 若真伤)
eps  = 总eq / cyc                    # 每刻等效倍率
```

**为什么必须换口径**：单发天花板在新引擎下是错的。
  
一个 `总eq 4.5 / cast 3.0 刻` 的重技与一个 `总eq 1.5 / cast 0.5 刻` 的快技，
  
在 spd 50 下的真实输出分别是 `4.5/3.8 = 1.18` 与 `1.5/1.3 = 1.15`——几乎持平，
  
但单发天花板会判前者"强 3 倍"。**没有 cast 的天花板是没有意义的。**

**两组上限，各管一件事**：

| 档        | 裸 eps 上限 | 条件后 eps 上限 | 观感帽（单发总eq） |
| -------- | -------- | ---------- | ---------- |
| 基础 1-28  | 0.85     | 1.05       | 2.0        |
| T1 32-58 | 1.00     | 1.30       | 2.6        |
| T2 62-88 | 1.15     | 1.50       | 3.6        |
| T3 90-98 | 1.30     | 1.75       | 4.6        |

- **eps 上限 = 平衡帽**：决定强不强，全部由脚本校验。
- **观感帽 = 数字帽**：只防单次伤害数字离谱（一击刻杀），不参与平衡判断。
- **条件倍率**（如"战意满层 ×1.4"）必须满足 `裸eps × 条件倍率 ≤ 条件后上限`，由脚本重算。

**多段红线**：`eps ≤ 同档单体 max eps × 1.10`（含"条件下追加段"，脚本要解析机制列）。
  
**AOE 红线**：单目标 `eps ≤ 裸上限 × 0.80`（AOE 靠目标数赚总量，不靠单目标效率）。
  
**真伤**：`总eq` 已 ×0.8，eps 自动生效，不再单列。

**记法铁律**（沿用 v152，已被 v152 审计证明有效）：

1. `base` = Lv.1 裸倍率，唯一真值源
2. `hits` 独立成列，`(×3)` 记法废弃
3. AOE 折扣折进 `base`，标 `[AOE]`，不在 eq 层另乘
4. `总eq / cyc / eps` 三列**由脚本生成，禁止手写**

## 一、战士 — 叠层「战意」

**形式**：战意叠在自己身上。**持有即强，常态不消耗**；每线各有 1~2 个「兑现技」（主动消耗战意换即时效果），这是例外不是常态。

```
战意 0-10 层
  获取：普攻/技能命中 +1，击杀 +2，受击 +1
  持有收益：每层 攻击 +4%（满层 +40%）
  持有代价：每层 受伤 +2%（满层 +20%）     ← 越强越脆
  衰减：战斗中不衰减（与时间无关）；战斗结束清零

  满 10 层 → 可开【狂暴】（玩家选择进/出，切换免费不占行动）
    狂暴中：普攻双段 2×70%，吸血 25%，攻击 +20%
    维持：每刻 −0.6 层；受击 −1 层（1 刻 内至多 −1）

## 二、法师 — 记账「元素印记」

**形式**：两条线共用「记账」形式，账本不同——元素线记**敌身**的火冰雷印（多条账目，可组合结算），奥术线记**己身**的奥术充能（待发能量，精算倾泻）。
与拳师「充能」的区别：拳师是单条进度推满即清；法师·元素是多本分类账、怎么组合才是决策；法师·奥术是单条能量账、什么时候倾泻才是决策。

```
元素印记（火/冰/雷，每系 0-3 层，记在单个敌人身上）
  记账：火系技能 → 火印 / 冰系 → 冰印 / 雷系 → 雷印
  衰减：无（生命周期 = 触发反应清除，或战斗结束）

  层数作用：该系结算倍率 1层 ×1.0 / 2层 ×1.2 / 3层 ×1.4

  结算（主动引爆，清空参与结算的印记）：
      火印 + 冰印 = 蒸发   伤害 ×1.30
      雷印 + 火印 = 超载   转为全体 AOE
      冰印 + 雷印 = 冻结   目标定身 1.5 刻
      雷印满 3 层 = 感电   连击 +1（印记保留，不结算）
```

### B 线 · 奥术 → **奥术学者 › 奥术大师 › 奥秘主宰**（充能往"精算"长）

> 深化方向：**奥术充能**（arcane，挂自己）。与元素线的区别——元素记**敌人身上**的火冰雷账，
> 奥术记**自己身上**的纯魔法能量账。但奥术线的深度不在"攒满爆发"，而在**精算**：
> 充能既是弹药、也是盾牌、还是先机。机制复用引擎现况（奥术直觉/深度冥想/奥术脉冲/奥术洪流已在 `skills.py` 的「奥秘法师」线）。

**奥术学者的三重张力**（这条线的灵魂）：

1. **爆发 vs 续航**——充能越高伤害越强，但「燃尽」清空后回到裸奔。早泄浪费充能，晚泄错过时机。这是**预算**，不是**赌命**。
2. **力场塑形**——同一股奥术能量，塑成**刃**（倾泻）还是**盾**（护盾）。用充能打输出，就没充能开盾；攻守一体。
3. **真知换先机**——奥术直觉（预读回充能）、法术反制（掐断咒语）用信息差换节奏。

```
奥术充能（arcane，0-5 层，挂自己）
  获取：奥术直觉（每刻自动 +1）；奥术技能命中 +1；深度冥想（架设中每刻额外 +1）
  消耗：奥术脉冲 / 奥术洪流 / 奥术湮灭（燃尽全部，每层追加）；相位偏折（充能转护盾）
  衰减：无（待发能量，不自然消散）
  满 5 层 → 奥术洪流「共鸣巅峰」、真知「满弦暴击」
```

## 三、游侠 — 预算「专注」（流量制重写）

**形式**：专注是**持续充能的预算**——像一条不断注水的水管，你不花就浪费，但也不会凭空攒出一大笔。

```
专注 0-100
  充能：每刻 +18（持续，不受行动次数影响）
  消耗：技能消耗专注（见「专注」列）；专注不足 → 该技能不可用
  结余奖励：施放时专注 ≥40 → 该次技能暴击 +15%（【凝神】）
  满槽：100（约 5.6 刻回满）
```

> **这是 v153 改动最大的一处。** v152 写的是"每回合重置为 100"——它寄生在回合上，
>   
> 回合没了以后"重置"这个动作没有触发时机，整条线空转。
>
> 改成**流量制**后，游侠的形式变成了"预算流速"问题：
>   
> 一场 49 刻的战斗总供给 ≈ 880 点，玩家约出手 20 次 → **平均每次出手可用 44 点**。
>   
> 技能专注消耗据此标定：小技 20~~30、中技 35~~45、大技 55~70。
>   
> 快技能（cast 小）可以在同样的时间里多打几次小额消耗，慢技能一次花掉大半槽——
>   
> **出手速度与预算流速的耦合，就是游侠的决策空间。**

**决策问句**：这管水怎么放？铺几个小技，还是攒一波打大的？要不要留 40 点换暴击？

**代价**：身板脆（后排）；专注是硬约束，大技用了小技就没得用。

## 五、刺客 — 计数「连段」

**形式**：连段是**命中计数**，不是货币。

```
连段 0-5（引擎 cp max 5，v152 虚标为 0-10，已修）
  命中 +1 段
  1.5 刻内未命中 → 连段减半（向下取整）
  被控、跳过行动  → 连段归零
  每段：暴击率 +6%（满段 +30%）
  终结技：伤害 ×(1 + 0.10 × 连段)，结算后连段归零
```

> **时刻制改造**：v152 的"未命中 → 减半"是纯事件语义，在刻制下仍然成立，
>   
> 但刺客 cast 只有 0.5~~1.0 刻、循环 1.3~~1.8 刻，一次 miss 就减半过于严苛。
>   
> 本版加一层时间缓冲：**1.5 刻内没有命中才判定断连**——正常连打不会掉段，
>   
> 只有被打断（被控 / 走位 / 目标死亡换目标）才真的断。
>   
> 这样"断连"从"运气惩罚"变成"节奏惩罚"，玩家可预防。

**决策问句**：续连还是收割？

**代价**：断连即损；连段越高越舍不得收，但收割窗口稍纵即逝。

## 六、拳师 — 充能「破绽」（速率制重写）

**形式**：破绽是挂在敌人身上的**单条进度条**，推满即清。与法师「记账」的区别：法师是多本分类账、怎么组合是决策；拳师是一条进度、推不推得满才是决策。

```
破绽条 0-125（挂敌人身上，全队共享；enemy_bar.shaken，载体 actor.effects["bar:shaken"]）
  推条：技能注入（值见各技能「推条」列；多段技为「每段」量，按段数合并注入）
  衰减：每刻 −1.7    ← v153 关键改动，见下方说明
  推满 → 目标【破防】：跳过其下一次行动（＝白损失一次行动），破绽清零
  阈值递增：每次触发后 ×1.35，封顶 ×2.5（50→67→90→121→125）
  免疫窗口：触发后 2 刻 内不再积蓄（期内推条被忽略）
  阶段转换：保留 50% 积蓄
  自锁防护：触发瞬间注入 = 0
  不吃异常免疫

## 七、吟游诗人 — 驻留「旋律」

**形式**：诗人唱一首歌，旋律作为**持续光环**驻留战场，直到换歌。诗人没有资源条，他的决策是"现在该唱哪首"。

```
驻留旋律（同时只能 1 首）
  起手（唱新歌）  → 旋律驻留，全队获得光环，持续到换歌；cast 0.6（快）
  吟唱（继续唱）  → 强度层 +1（上限 5），cast 1.2
  终章（满层爆发）→ 强度达 5 时，下一次「吟唱」自动变为「终章」：
                     cast 2.4，触发该旋律的终章效果，强度清零，**旋律继续驻留**
  强度层 → 每层光环效果 +20%（5 层 = +100%）
  代价   → 旋律驻留期间不能普攻（专心演唱）
```

> **时刻制适配**：旋律常驻至换歌，与时间推进无关——驻留是七个形式里最不需要改的一个。
>
> **【终章】在 v152 是孤儿机制**（定义了"强度 5 触发终章"，但没有任何技能定义终章效果）。
>   
> v153 补齐：**每条旋律自带一条终章效果**，写在旋律技能的机制列里（标 `终章：`）。
>   
> 终章不是一条独立旋律，而是**该旋律在满强度时的一次性爆发**，放完强度归零、旋律继续，
>   
> 所以终章是可循环的爆发窗口，不是一次性消耗品。

**决策问句**：唱哪首？继续吟唱堆强度换终章，还是换歌应对新情况？

**代价**：诗人自身脆弱（后排），且旋律驻留期间不能普攻。

### 9.3 DOT 结算（毒/灼烧/流血/腐蚀）

```
每层每刻伤害 = (atk×a + matk×m + max_hp×h) × 层数 × mult × (1 − 总抗)
DOT 每 1.0 刻 跳一次（dot_tick 事件，ACT_TICK=1.0）
总抗 = min(0.95, dot_res + adapt)      # 连续叠层 adapt 递增，2 刻 未叠 −4% 消退
immune_dots 命中 → 直接移除不结算
corros（腐蚀）→ true_dmg 分支，绕过 def/mdef（但不豁免目标异常抗性）
```

> **DOT 强度必须用 eps 口径复核**（v153 新增）：poison 2 层 = atk×1.0 + hp×3% **每刻**，
>   
> 对比 T2 普通单体技能 eps ≈ 0.92——**DOT 单层刻伤已经接近主动技能**，
>   
> 所以 DOT 的层数上限（毒 5/8、灼烧 3、流血 2）就是它的强度阀门，调平衡优先动层数不动系数。
