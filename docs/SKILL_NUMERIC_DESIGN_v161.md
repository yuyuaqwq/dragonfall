## 二、公式模板（LOL/魔兽/暗黑 共同结构）

```
伤害 = 基础值(技能等级成长) + 加成系数 × 主攻属性
     = base(1 + per_lv×(skill_lv-1)) + ratio × atk/matk
```

- **基础值**：保底，随技能等级成长（每级线性），低装备不刮痧
- **加成系数**：装备/加点收益，后期主导
- **比例设计**：前期基础值占比 60-70%（保底）→ 后期加成占比 60-70%（成长）
- **技能等级成长**：基础值线性（每级固定增量），加成系数固定（LOL 标准）

## 三、技能定位（v150 设计文档已定义，需对齐 v153 代码）

每个攻击技能按设计意图分四类，EQ 天花板不同：

| 定位 | 特征 | EQ 目标 | 例子 |
|---|---|---|---|
| 填充技 | 低CD/无CD，常按 | 1.0~1.3 | 挥砍、火球术 |
| 核心技 | 中CD，主力输出 | 1.5~2.5 | 猛击、陨石术 |
| 爆发技 | 长CD/高资源，单发狠 | 2.5~3.5 | 蓄力斩、元素风暴 |
| 终结技 | 资源倾泻，满资源最强 | 3.5~4.5 | 战争化身 |

## 四、反推流程（每个技能）

```
1. 定位：该技能在循环里的角色（填充/核心/爆发/终结）→ EQ 目标
2. 目标伤害：EQ × 当前主攻属性（对齐击杀轮数）
3. 拆 base/ratio：
   前期占比：base 占 60-70%
   base_lv1 = 目标伤害 × 0.65（除以 1 份属性贡献）
   ratio = 目标伤害 × 0.35 / 主攻属性
4. 成长：base 每级 +15~20%（LOL 惯例）
5. 落地：exprs 数组（每级基础值）或单条 expr（线性成长）
```

## 五、职业成长补偿（鱼鱼核心需求）

**低攻职业（坦克型加点）基础值占比更高**：

| 职业 | 加点倾向 | 主攻属性 | base 占比 | 补偿逻辑 |
|---|---|---|---|---|
| 战士 | str+vit 混 | atk（Lv45≈211 坦克型） | 70% | 基础值高，加耐力也打得动 |
| 拳师 | str+vit 混 | atk（Lv45≈191 坦克型） | 70% | 同上 |
| 刺客 | agi 主 | atk（高） | 45% | 加成高，高攻收益大 |
| 游侠 | agi 主 | atk（高） | 45% | 同上 |
| 法师 | int 纯 | matk（高） | 55% | 居中 |
| 牧师 | int 纯 | matk（高） | 55% | 居中 |

**验证**：坦克型战士（4str:6vit）打出的技能伤害 ≥ 全攻战士的 85%（否则补偿不足）

## 八、后续扩展（鱼鱼 2026-09-01 提出，样板完成后思考）

**数值矩阵多加点点位**：当前 32章 1.1 只测"全攻加点"一种——实际玩家加点多样（坦克型 4str:6vit / 平衡型 / 输出型），数值模型应覆盖：
- 每职业 × 多种加点方案 × 各阶段（P1-P5）的 DPS/HP/承伤
- 验证目标：任何合理加点都不刮痧（坦克型伤害 ≥ 全攻型 85% 已做）；任何加点都不超模（输出型也不碾压）
- numeric_lib `stage_scan` 增加加点参数，矩阵报告加"加点列"

**综合职业自带成长曲线**：职业基础成长率差异（战士 atk 3.4/级、法师 matk 4.1/级等）是数值模型的隐藏变量——技能 base/ratio 设计应与职业成长曲线联动（成长快的职业 ratio 高，成长慢的 base 高），避免"成长快的职业后期碾压 / 成长慢的后期刮痧"。
