## 1. 背景与目标

### 1.1 现状问题（v110 审计结论摘要）

1. **13 隐藏 > 6 基础**，"隐藏"稀缺感稀释；隐藏线数量已无内容支撑继续膨胀。
2. **隐藏三转是"等级里程碑"而非"转职"**：`evolve_branches` 单分支线性档位，玩家"转了三次无分叉"落差（v110.15 已修正命名与叙事，结构性落差仍在）。
3. **同源隐藏定位重叠**：法师系 3 隐藏全输出（奥术/虚空/猩红）、游侠系 3 隐藏全输出（星辰/丛林/兽语）。
4. **维护成本**：75 个档位名、13 条解锁任务链、~150 个隐藏职业技能，每次平衡调整过 19 职业。

### 1.2 重构目标

1. **数量收敛**：19 职业 → 12 职业（6 基础 + 6 隐藏，每基础 1 条隐藏线）。
2. **深度替代广度**：每条隐藏线内做 **2-3 个流派**（T1 觉醒时选择），原 13 线机制全部保留、按流派归组——"更深的流派与特色"。
3. **隐藏技能书系统**：跨线稀有/通用特殊技能通过"隐藏技能书"学习，扩展玩法且不依赖职业线。
4. **零删减原则**：机制、数值、技能、任务内容**全部保留或重组**，不砍内容只改归属（P0-4）。
5. **存档无损**：已转职玩家按 §7 映射自动迁移。

## 3. 目标架构

```
6 基础职业（不变：战士/法师/游侠/牧师/刺客/拳师，三转×攻守分支不变）
  └─ 6 隐藏线（每基础 1 条，T1 觉醒时选流派，T2/T3 沿流派深化）
       战士线：★龙裔誓约（候选：誓约战士/龙裔骑士）——流派：龙血 / 圣誓 / 魔剑
       法师线：★奥秘术士（鱼鱼提名）           ——流派：元素 / 深渊 / 血咒
       游侠线：★荒野猎手（候选：星野猎手）     ——流派：星运 / 自然 / 兽群
       牧师线：★圣歌神谕（候选：神谕者·堕落）  ——流派：圣歌 / 暗影
       刺客线：★暮影（保留名）                 ——流派：暗杀 / 收割
       拳师线：★苦修（保留名）                 ——流派：武僧 / 大地

隐藏技能书系统（跨线通用/稀有特殊技能，任何职业可学或限源流）
```

### 3.1 与现有机制的关系（全部复用，零新引擎）

## 4. 六条隐藏线详细设计

### 4.1 战士线「★龙裔誓约」（候选：誓约战士 / 龙裔骑士 / 圣剑誓约）

- 定位：坦克/输出复合（原三线定位的并集），T1 觉醒三选一
- 流派与机制归属：

| 流派 | 吸收自 | 机制清单 | 技能组（吸收自） |
|---|---|---|---|
| 龙血 | 龙血战士 | 真伤（龙息之怒 0.8）、火之亲和（灼烧×1.2）、龙魂 elem_res+5%、龙鳞 | sk_long_hun 等龙血全套 |
| 圣誓 | 圣殿骑士 | 护盾、格挡反击、圣光增伤（对暗/亡灵）、圣光审判 | 圣殿全套（坚盾壁垒等） |
| 魔剑 | 魔剑士 | 魔能涌动（普攻 magi）、符文刻印充能、咒刃 | 魔剑全套（元素弹幕附魔等） |

- 档位名（P0-1）：T1 龙裔誓约（觉醒）→ T2 ★龙誓骑士（候选：龙符剑士）→ T3 ★誓约之王（候选：龙咒圣王）
- 数值基调：保留原三线面板差（龙血/圣殿 ≈ 基础±0~8%、魔剑 +11.7% 为流派上限）——流派即数值分档

### 4.2 法师线「★奥秘术士」（鱼鱼提名）

- 定位：输出（元素/深渊/血咒三向），T1 觉醒三选一
- 流派：

| 流派 | 吸收自 | 机制清单 |
|---|---|---|
| 元素 | 奥术师 | 元素爆发（元素弹幕）、奥术印记叠层引爆、大魔导师系 |
| 深渊 | 虚空行者 | 虚空爆破（吸蓝 15%）、深渊系、虚空先知 |
| 血咒 | 猩红学者 | 血魔法（hp_cost 10%×1.3）、血之契约、血之君主 |

- 档位名：T1 奥秘术士 → T2 ★奥秘贤者（候选：秘法大师）→ T3 ★奥秘君王（候选：大奥秘师）
- 注：原"奥术师/奥法大师/大魔导师"名字下沉为流派内档位名或技能书名（避免与基础法师守线"秘法"族冲突）

### 4.3 游侠线「★荒野猎手」（候选：星野猎手 / 自然猎手）

- 定位：输出（星运/自然/兽群三向）
- 流派：

| 流派 | 吸收自 | 机制清单 |
|---|---|---|
| 星运 | 星辰猎手 | luck→暴击（cap+12%）、幸运一击（30% 追加 50%）、命运之轮 |
| 自然 | 丛林猎手 | 毒爆（毒层≥3 引爆）、荒野、苍林 |
| 兽群 | 兽语者 | 单宠进化（幼狼→狼王→影狼真伤）、summon_power 挡刀率 cap85% |

- 档位名：T1 荒野猎手 → T2 ★荒野追猎者（候选：星野猎手）→ T3 ★万灵猎王（候选：荒野之王）

### 4.4 牧师线「★圣歌神谕」（候选：神谕圣者 / 堕影神谕）

- 定位：辅助/输出双极（圣歌=辅助，暗影=输出），T1 觉醒二选一
- 流派：

| 流派 | 吸收自 | 机制清单 |
|---|---|---|
| 圣歌 | 吟游诗人 | 安眠曲睡眠、战歌、轻风咏叹速度、哀歌沉默、黎明颂歌 |
| 暗影 | 暗影祭司 | 骷髅海（3 骷髅）、死亡契约、牺牲替死、亡魂引渡 |

- 档位名：T1 圣歌神谕 → T2 ★圣歌主教（候选：灵歌主教）→ T3 ★圣歌大主教（候选：黎明神谕）
  （暗影流派内部档位名沿用 亡魂引渡者/黯灵主教 作为流派称号）

### 4.5 刺客线「暮影」（保留名）

- 定位：输出，T1 觉醒二选一
- 流派：

| 流派 | 吸收自 | 机制清单 |
|---|---|---|
| 暗杀 | 暮影·潜行向 | 暗影步潜行必暴、幽影袭、影之国度 |
| 收割 | 暮影·斩杀向 | 斩杀（<30% +40%）、残血追猎、幽影刃 |

- 档位名：T1 暮影行者 → T2 暮刃大师 → T3 暮影收割者（v110.15 定稿名保留）

### 4.6 拳师线「苦修」（保留名）

- 定位：输出，T1 觉醒二选一
- 流派：

| 流派 | 吸收自 | 机制清单 |
|---|---|---|
| 武僧 | 苦修士·连击向 | 连击（三连 0.50）、气力、战意 |
| 大地 | 苦修士·体术向 | 反击、磐石体、大地武僧系 |

- 档位名：T1 苦修士 → T2 大地武僧 → T3 撼岳者（v110.15 定稿名保留）

### 4.7 流派与技能书的关系

- 流派技能 = 该流派核心技能组（进分支技能表，T1 选流派后按 skill_up 学习）
- **隐藏技能书 = 跨流派/跨职业稀有技**，如：
  - 「龙息之怒」（真伤）→ 技能书，战士源流可学（不选龙血流派也能学）
  - 「影狼召唤」（兽群真伤宠）→ 技能书，游侠源流可学
  - 「血之契约」（血魔法通用版）→ 技能书，法师源流可学
  - 新增内容位：未来新特殊技能统一走技能书（不再开新职业线）
