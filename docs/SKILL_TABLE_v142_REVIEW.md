# 《全职业技能组详表 v142》设计评审

> 评审对象：`docs/SKILL_TABLE_v142.md`  
> 核对方式：AST 解析 `game/data/skills.py`（PLAYER_SKILLS / BRANCH_SKILLS / \_ADD_HIDDEN_SKILLS / TUTOR_SKILLS）+ `classes.py` + `engine.py` / `battle.py` 伤害链路 + `core/constants.py`  
> 结论分三层：P0 架构 / P1 数值 / P2 表达。每条都给出可验证的数据，不含主观偏好项。



---

## 总体判断

骨架是好的。12 职业各配一套专属资源、v139 那批形态机（狂暴/架设/凝滞/影舞/龙焰）与挂敌身条（破绽/诅咒/链值）让每个职业有了真正不同的手感，这在同类文字 RPG 里属于中上水准。「基础职业 = 教科书、转职 = 资源入场券、隐藏线 = 进阶变奏」这条设计哲学也立得住。

问题不在创意层，在**工程一致性**上：这些内容经历过 v130.2 瘦身、v133 红线、v139 融合等多轮改造，每轮都在局部改数值和文案，但没有一次回头统一口径。累积下来的结果是——**这份表格已经不能用来做平衡判断了**。

下面按严重度排。

---

# P0 · 架构层

## P0-1 隐藏六职业只有基础职业 27% 的技能量

实测（含基础线 + 转职三档 + 觉醒被动）：

| 职业     |     技能总数 | 职业     |          技能总数 |
| ------ | -------: | ------ | ------------: |
| 法师     |       47 | 时咒法师   |            13 |
| 牧师     |       43 | 暗影神谕   |            13 |
| 战士     |       42 | 星语者    |            12 |
| 游侠     |       42 | 龙裔誓约   |            11 |
| 拳师     |       42 | 淬势者    |            10 |
| 刺客     |       39 | 暮影行者   |         **9** |
| **平均** | **42.5** | **平均** | **11.3（27%）** |

`_ADD_HIDDEN_SKILLS` 里每个隐藏职业只有 1–2 个觉醒被动，其余全在 `BRANCH_SKILLS`。

**为什么这是问题**：`src_base` 字段（战士/法师/…）目前只被 `job_guide` 用于显示「渊源：由战士一脉传承」和 `player.py:809` 的种族血脉校验，**不继承任何技能**。所以隐藏职业的全部战力就是那 9–13 个技能 + 转职前已学会的源职业技能。玩家花力气解锁 40 级任务链，换来的技能池反而比坚持基础线更窄，且隐藏职业单线无分支，build 空间进一步压缩。暮影行者 9 个技能里连一个减伤/自保技都没有。

**建议**：隐藏职业补到 22–26 个（约基础职业的 55–60%，留出「继承源职业」的合理差值）。T1/T2/T3 各补 3–4 个，优先级：暮影行者 > 淬势者 > 龙裔誓约。补的方向优先填缺口（位移 / 生存 / 反击），而不是再加第 4 个爆发技。

## P0-2 隐藏职业三转门槛比基础职业早 15–25 级

|       | T3 技能等级                         |
| ----- | ------------------------------- |
| 基础六职业 | 90 / 92 / 94 / 98               |
| 龙裔誓约  | 75 / 80                         |
| 星语者   | 75 / 78 / 80                    |
| 暮影行者  | 75 / 80 / 85                    |
| 淬势者   | 75 / 80 / 82                    |
| 暗影神谕  | **70** / 72 / 74 / 76 / 78 / 80 |

暗影神谕 70 级就能放三转奥义，基础职业要 90。如果这是「解锁隐藏线的奖励」，文档必须写明；如果是历史遗留，建议两边统一到 **88 / 92 / 96**。建议：文档里加一行「隐藏线为进阶奖励，三转提前 15 级，数值已按同等级强度折算」——只要口径明确，这不必然是 bug。

## P0-3 战士和游侠没有导师秘传

`TUTOR_SKILLS` 实测：

| 职业     |    数量 | 技能        |
| ------ | ----: | --------- |
| 法师     |     1 | 魔力脉冲      |
| 牧师     |     2 | 圣光惩戒、救赎之光 |
| 刺客     |     1 | 淬毒之刃      |
| 拳师     |     2 | 裂骨击、磐石之体  |
| **战士** | **0** | —         |
| **游侠** | **0** | —         |

2/6 的基础职业在这一栏是空的。导师 NPC（`classes.py` 的 `tutor` 字段）是每个职业都配了的，玩家找到战士导师会发现没东西可学。

另外导师技能等级是 lv6–10，倍率 130%–170%，在 lv100 环境里纯属收藏品。建议：补齐战士/游侠各 2 个，并把导师技改成随等级成长（复用 `skill_power_mult`），或定位为「转职前后的签名过渡技」明确写清楚用途。

# P1 · 数值层

## P1-1 表格里的 `power` 和「说明」列是两套口径，48 个技能对不上

这是全表最影响可用性的一条。实测 160 个伤害技中，**48 个（30%）的 `power` 与文案承诺倍率偏差超过 ±8%，偏差范围 0.08× ~ 2.50×，且没有统一换算公式**。

偏差最大的（单向：实际 power 全部低于文案）：

| 技能          | power |   文案 |     实测 |        偏差 |
| ----------- | ----: | ---: | -----: | --------: |
| 终结·处刑（刺客）   | 1.598 | 400% | 159.8% | **2.50×** |
| 影刃（刺客）      | 1.151 | 285% | 115.1% |     2.48× |
| 暗影处刑（刺客）    | 1.317 | 320% | 131.7% |     2.43× |
| 裂地斩（战士）     | 0.816 | 180% |  81.6% |     2.21× |
| 圣光惩击（牧师）    | 0.905 | 200% |  90.5% |     2.21× |
| 终结·暗影绞杀（刺客） | 2.347 | 500% | 234.7% |     2.13× |
| 暗杀（刺客）      | 1.147 | 240% | 114.7% |     2.09× |
| 战争化身（战士）    | 2.396 | 500% | 239.6% |     2.09× |

（末尾另有 4 条 0.08×–0.5× 的是脚本把「每点怒气+12%」这类增量数字误读为承诺倍率，属误报，已排除。）

刺客线几乎整体虚标 2–2.5 倍，战士线 2.0–2.2 倍。

**根因**：`power` 是引擎基础值，`desc` 文案在不同时期按不同口径书写——有的含满级成长 ×1.4，有的含条件触发倍率，有的两个都含。逐次数值调整时只改了其中一边。

## P1-2 表格缺失「技能等级成长」和「pmult 乘区」两套规则

`battle.py:3666` 的实际伤害链路：

```
dmg = atk × power × pmult
pmult = skill_power_mult(技能等级)   # 1.0 ~ 1.4（每级 +10%，上限 5 级）
      × frozen_bonus × stealth_mult × stack_bonus × cond_mult
      × magic_bonus × passive_bonus × reaction_mult
      × affix_mult × elem_mult × race_mult × v139_形态倍率
      ── 12 个乘区连乘，clamp 到 SKILL_PMULT_CAP = 6.0
暴击 / 暴伤 / 幸运一击 = 独立乘区，不受 6.0 限制
```

**表格里这两套规则一个字都没提**。后果很直接：读者看到「暗杀 power 1.147」会以为这是个 114% 的弱技，实际满级 + 残血条件是 114.7% × 1.4 × 1.6 ≈ 257%。反过来，想判断两个技能谁强，用表里的 `power` 排会得出错误结论。

**建议**：在「阅读说明」后加一节「伤害公式」，把上面这段贴进去；表格增加 `基础%`（power×100）和 `满级%`（power×1.4×100）两列，删掉现在含混的「说明」列倍率；文案统一为「满级 + 条件触发时」口径并在 `desc` 里标注。

## P1-3 多段技等效倍率倒挂单体终极技

`power × multi` 排序 TOP：

| 技能            |    等效总倍率 | 段数 | 对比同职业单体终极技   |
| ------------- | -------: | -: | ------------ |
| 无影连打（拳师 lv92） | **650%** |  5 | 气力天地 500%    |
| 风暴之舞（游侠 lv92） |     562% |  4 | 疾风骤雨 505%    |
| 致命连射（游侠 lv92） |     560% |  4 | 死神之箭 450%    |
| 幻影舞（刺客 lv92）  |     500% |  5 | 终结·暗影绞杀 500% |
| 急速射击（游侠 lv62） | **450%** |  5 | 死神之箭 450%    |

拳师 lv92 的常规技比 lv98 终极技高 30%；游侠 lv62 的常规技就已经等于 lv98 终极技。多段还额外享受命中类收益（怒气/连击点/印记按段结算）。

v133 已经加了 `MULTI_HIT_CRIT_FIRST_ONLY = True`（多段仅首段吃暴击），峰值爆炸缓解了，但基础倍率倒挂没修。建议：多段技单段统一 ×0.85，或设红线「多段总倍率 ≤ 同档单体技 × 1.15」。

## P1-4 真伤与控制密度集中在个别职业

| 职业       | 技能数 |        真伤数 |       带控制数 |    控制占比 |
| -------- | --: | ---------: | ---------: | ------: |
| 龙裔誓约     |  11 | **5（45%）** |          0 |      0% |
| 时咒法师     |  13 |          0 | **4（31%）** | **31%** |
| 其余 10 职业 |   — |        0–1 |        0–3 |    0–8% |

**龙裔誓约**：11 个技能里 5 个真伤（龙焰初击/龙息/龙爪/龙焰吐息/龙脉终曲）。真伤绕过全部减伤，坦克可以同时堆防御和输出不衰减，对高防 Boss 尤其失衡。建议保留 2 个真伤做签名（龙焰吐息/龙脉终曲），其余改成物理 + `pierce`。

**时咒法师**：减速 ×2、眩晕 ×2、停滞 2 回合、必眩晕奥义。「停滞 2 回合」在回合制里接近无解。而且除安眠曲外，没有任何技能标注首领抗性。建议加全局「同一目标 3 回合内控制效果递减 50% → 100%」，并对首领固定 1 回合。

# P2 · 表达层

## P2-1 有 8+ 个机制字段出现在技能表里，但没在「字段释义 / 核心资源一览」登记

表格里反复出现却查不到定义的：破绽条、链值、磐核、气力层、灵魂标记、诅咒、骨噬、回声、圣律、龙焰态、影舞态、屏息窗口、凝滞态。

其中「破绽」在淬势者里高频出现（6 个技能带「破绽推条+1」），但核心资源表里根本没有破绽条这一项。读者无法判断破绽条上限、如何消耗、满了会怎样。

## P2-2 召唤物机制完全未定义

暗影神谕 13 个技能里 5 个依赖骷髅（召唤骷髅 / 骷髅海 / 献祭暗焰 / 骸骨洪流 / 死亡契约），游侠有藤蔓守卫与古树守卫。但骷髅的 HP、ATK、继承比例、行动规则、是否吃 AOE、破盾条件，文档一个字都没有。这是目前最大的机制盲区——职业一半的强度建立在未定义的实体上。建议补一节「召唤物属性表」。

## P2-3 class key 与展示名不符，两组拼音撞车

| key               | 展示名  | 问题                           |
| ----------------- | ---- | ---------------------------- |
| `cls_wild_hunter` | 星语者  | key 意为「野性猎人」，与展示名无关          |
| `cls_hymn`        | 暗影神谕 | key 意为「赞美诗」                  |
| `cls_wu_seng`     | 拳师   | 拼音是「武僧」                      |
| `cls_wu_sheng`    | 淬势者  | 拼音也是「武僧」，且其 T1 分支 key 就叫「武僧」 |

`cls_wu_seng`（拳师）和 `cls_wu_sheng`（淬势者）只差一个字母 `g`，而两者的分支命名还撞在一起。代码维护时极易出错。改动牵连存档，建议不要硬改 key，而是加一层展示名映射 + 在文档里标注 key 与展示名的对应表。

## P2-4 表格列结构三套并存

T1 表有独立的「机制/条件」列；T2/T3 表把 CD、资源、机制全塞进「说明」列；基础技能表又多一个「元素」列。同一份文档三种表头，人工阅读和脚本解析都难受。建议统一列集，缺失值用 `—`。

## P2-5 双线命名对部分职业不成立

「攻线/守线」对战士、牧师、拳师是准确的，但：

- **游侠**：林语者（标记/毒/持续）vs 风行者（速度/爆发）——两条都是输出，没有「守」。建议改「持续 / 爆发」。
- **法师**：元素 vs 奥秘，实际是「印记反应 / 叠层高频」，攻守分工也弱。
- **刺客**：影舞 vs 毒刃，是「影 / 毒」，与攻守无关。

建议按职业用不同的双线标签，比强行统一成「攻/守」更清楚。

## P2-6 隐藏六职业有 5 个定位是「输出」

龙裔誓约（坦克）+ 其余 5 个全是输出，没有一个治疗或纯辅助。而暗影神谕的技能组实际是「召唤 + 团队增益 + 半额回血」，标「输出」名不副实；时咒法师控制技占 31%，更像控制位；淬势者禅意每点 +4%、撼岳之势带震慑，偏半坦。建议把定位标签改准：暗影神谕 → 召唤/辅助，时咒法师 → 控制/输出，淬势者 → 半坦/输出。这只是标签，不改数值，但能显著降低玩家的职业选择误判。

# 附：牧师攻线的一处属性割裂（P1，单点）

吟游诗人线的音刃（即兴弹唱 100%、轻快拨弦 110%、破晓长歌 320%）**全是物理伤害**，但牧师的增益技能（信仰祈祷 / 神圣祷言 / 奥术咏叹调）**全是魔攻 +50%**。攻线牧师的核心输出吃不到自己职业的全部增益，而牧师主属性成长也在魔攻侧。

两条修法：把音刃改成魔法伤害（推荐，一步到位），或把「战歌」系增益从「魔攻 +30%」改成「全伤害 +30%」。

另外「自身仅享 55%」这个惩罚在战歌/启明圣咏/轻风咏叹/奥术咏叹调/死歌三调上重复出现 5 次，文案啰嗦且惩罚是否叠乘未说明。建议抽成一条统一机制（如「共鸣衰减：歌者自身享有团队增益的 55%，该衰减不叠乘」）写在字段释义里。

# 建议的修改顺序

1. **先补口径**（P1-1 / P1-2）——加「伤害公式」章节 + `基础%`/`满级%` 两列。这一步做完，后面所有平衡讨论才有共同基准，工作量也最小。
2. **再补机制定义**（P2-1 / P2-2）——破绽条、链值、磐核、召唤物属性表。
3. **然后动结构**（P0-1 / P0-2 / P0-3）——隐藏职业技能量、三转门槛、导师秘传。这三项需要新增数据，工作量最大，建议单独排期。
4. **最后收尾**（P1-3 / P1-4 / P2-3~P2-6）——倍率红线、真伤与控制密度、命名与表格结构。

第 1 步建议优先做。现在这份表 42% 的数值行是「看起来能比、实际不能比」的状态，任何基于它的平衡调整都是在沙上建塔。
