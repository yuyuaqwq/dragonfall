## 一、诊断：现有技能为什么"太重复"

对 6 基础职业全量技能表扫描（17~18 个/职业 → skill_up 逐级配置）结论：

| 症状 | 证据 | 根因 |
|---|---|---|
| 伤害技模板化 | 战士 6 个伤害技能全是 `物理 pow=1.0~2.5 + 条件加成`；刺客 6 个全是 `连击点+数值`；拳师 8 个全是 `气+数值` | 伤害主轴只靠 power 系数+一个 cond 条件区分，缺少职业专属循环 |
| 增益技换皮 | 战吼/铁壁/蓄势(战士) ≈ 圣佑/圣歌(牧师) ≈ 灵甲(法师)，全是 `atk_up/def_up/matk_up 30% 3回合 CD3` 同一模板 | 增益机制无职业差异化 |
| 被动技复制 | `atk(battle_start)x0.08` 战士+拳师一模一样；`dmg_taken减5%` 战士+拳师一样；`hp_high_70 def/matk x0.08` 同模板 | 被动是通用模板复制 |
| 终结技同公式 | Lv.30 全变成 `全耗资源每点+X% + HP<30% x1.5`：战士250%全耗怒气/牧师治疗全耗信仰/刺客3.0全耗CP/拳师3.0全耗气 | 资源不同但循环公式完全相同 |
| 资源循环同质 | 怒气/连击点/气 全是"攒点→放终结技"同一套积累-消耗，无差异化策略深度 | 核心资源只定义了获取/消耗，没有定义"打法节奏" |
| 分支仅数值延续 | 分支技能多数是"同机制更高数值"，分支间缺机制差异 | 攻线/守线方向没做进技能组 |

**核心结论**：技能重复的根因不是数量，是**机制层缺少"每职业专属策略循环"**。强弱只是系数差异，玩家感受不到"我是战士所以我要这样打"。

## 二、设计目标

1. **每条职业线打造一个专属"策略循环"**（signature loop）——玩家围绕它决策，其他技能为它服务。
2. **明确渐强/爆发/平稳三种节奏**：满血叠层渐强（ramp）、资源蓄满一波带走（burst）、稳定持续+反制（sustain）。每条线的攻线=一种节奏、守线=另一种，隐藏线=极致变奏。
3. **每个伤害技能三形态标准**（12 章既有标准，强制）：基础 + 🔄派生（连携变化）+ ⚡条件（战场适应）。
4. **数值合理**：转职必变强、消耗按等级、等效威力可算、SKILL_UP 全覆盖。
5. **职业可改**：位置/攻守定位/核心资源可动，理由充分即可（文档里写明）。

## 三、6 条职业线重设计方向（初始主张，子 agent 深化）

### 1. 战士线 cls_zhan_shi（怒气 / 隐藏=龙力）
- **现有**：17 基础技；攻=狂战士(5)/狂战统领(3)/战争领主(3)；守=盾卫士(4)/坚盾卫士(3)/坚城统帅(3)；隐藏=龙裔誓约(龙血真伤+灼烧)
- **特色循环**：**血线博弈**。渐强=「热血沸腾」低血&蓄力叠层渐强；爆发=怒气满值无畏冲击；平稳=格挡/受击回怒/反击循环
- **攻线**（狂战士系）＝渐强+爆发：叠层（蓄势/怒意层数）→ 血线越低攻击越高 → 满怒爆发。**守线**（盾卫士系）＝平稳坦克：受击回怒+嘲讽+格挡反击（把"受击"变成资源来源）。**隐藏**（龙血）＝真伤+灼烧 DOT 渐强（无视防御持续压血）
- **可改点**：怒气获取触达（on_hit 受击回怒已有）；考虑「姿态」双机制（热血/冷静）

### 2. 法师线 cls_fa_shi（元素亲和 / 隐藏=时之沙）
- **现有**：18 基础技（火冰雷标签但无真反应循环）；攻=元素；守=奥秘（护盾/法力）；隐藏=时咒法师（时停）
- **特色循环**：**元素反应连锁**（爆发节拍）。火→燃烧、冰→冻结/减速、雷→传导；按序释放触发组合反应。攻线＝反应连环爆发。守线（奥秘）＝法力护盾+破法射线（平稳输出+生存）
- **隐藏**（时咒）＝时间操控：时滞/凝时/时停，延迟爆发+行动节奏控制
- **可改点**：元素亲和 max=1 资源太薄——考虑元素三档切换（火/冰/雷各一档=元素槽），或引入"元素印记"叠层；**时停是稀有机制要留**

### 3. 游侠线 cls_you_xia（精力 / 隐藏=猎印）
- **现有**：17 基础技（精力消耗体系）；攻=林语(自然毒藤+植物召唤)；守=风行(高速连射)；隐藏=星语者(占星)
- **特色循环**：**标记猎杀**（节奏连环）。挂标记→打标记伤害→回精力→再挂；攻线＝毒藤+自然手段持续压血+植物召唤（渐强/缓慢铺场）。守线＝高速多动连射（爆发频次高、精力回转快）
- **隐藏**（星语）＝占星命运：随机 buff 触发的运气流+命运重掷（平稳/娱乐向）
- **可改点**：精力 regen=30/回合 是唯一有自然回的资源——可保留（游侠的"平稳"标签）；隐线星语 0 命中率超低需重做方向

### 4. 牧师线 cls_mu_shi（信仰值 / 隐藏=悼咏）
- **现有**：17 基础技；**攻线数据只有吟游诗人单线(8/7/7)——神谕者 branch 数据缺失（数据-职业不对齐）**；守=神谕者/大主教/圣光先知；隐藏=暗影神谕(骷髅海)
- **特色循环**：**圣光双循环**：治疗/圣光技产信仰 → 消耗信仰放神迹（群疗/神威/复活）。攻线＝歌声持续团辅（渐强 buff 叠层）。守线＝单奶/复活/神威（平稳爆发并存）
- **隐藏**（暗影神谕）＝亡者召唤：骷髅海铺场+死亡契约（以法力/生命换召唤物，爆发场面）
- **可改点**：**修复攻线双分支数据缺失**（吟游诗人单线 vs classes.py 声明的 [吟游诗人, 神谕者] 不对齐）→ 补神谕者分支或调整 classes/技能表；复活机制是稀有独占

### 5. 刺客线 cls_ci_ke（连击点 / 隐藏=影步）
- **现有**：16 基础技；攻=影舞(高速连击)；守=毒刃(DOT)；隐藏=暮影行者(暗杀)
- **特色循环**：**暴击-连击点-终结**爆发循环。攒点（普通技/暴击快速攒）→ 终结技爆发；攻线＝高连击快速攒点爆发（倒霉被闪就节奏崩——有学业成本）。守线＝毒叠层爆发（渐强，慢热但稳定）。隐藏＝影步潜行**一击必杀**（究极爆发，代价=脆）
- **可改点**：连击点 max=5 可保留；毒刃线 DOT 叠层要与"渐强"绑定做深；潜行机制是稀有独占（目前 stealth effect 已有）

### 6. 拳师线 cls_wu_seng（气 / 隐藏=禅意）
- **现有**：16 基础技；攻=格斗(连段)；守=磐石(铁壁反击)；隐藏=苦修士(禅意)
- **特色循环**：**连招循环+受击反击**（平稳+反制）。攻线＝连段 combo 递增（渐强，每段伤害+伤害频率↑）。守线＝格挡/铁壁/反击（受击换气+反弹，平稳坦克）。隐藏（武僧禅意）＝气积累节奏控制+气力爆发
- **可改点**：连段机制目前碎片化（combo_boost 被动存在但缺主轴）→ 做"连招段数"成长收益；武僧线"禅意"要西幻化命名（武僧→苦修士已西幻化，技能词避佛教词）

## 五、数值铁律（子 agent 必须遵守）

1. **转职必变强**：分支 Lv.32 等效威力 ≥ 基础 Lv.30×0.95。连击类等效 = power×multi；全耗资源类 = power×(1+per×max)
2. **基础大招 Lv.30** ≈ 等效 power 4.8（战士无畏冲击当前=全耗怒气每点15%×10=250% 属达标）
3. **消耗按等级**：费用随技能等级爬升不按百分比；数值凑整（100 级≈1000 金币风格）
4. **每技能独立 SKILL_UP 配置**（不允许零消耗/无升级配置的技能）
5. **团队技能每职业 ≥1**
6. **技能数对称**：基础 15~19 个（11~12 主动+4~5 被动），分支每职业 tier1 4~8 / tier2 3~4 / tier3 3~4，可微调但全职业口径一致
7. cond 条件 ≈ ⚡战场适应；派生（🔄）≈ 连携变化——desc 必须写清楚触发条件
8. **显示规范**（desc 文案）：
   - 消耗行：`消耗：N 魔力 ｜ 资源 -N ｜ 射程：N`（资源消耗=扣减用 `-`）
   - 百分比/增减描述必须带属性名（`受物理伤害-10%` 不是 `-10%`）
   - 禁止玩家可见文本出现内部 ID（sk_/cls_/rec_/mat_ 前缀）
   - 数值正负号两侧带空格（`攻击 + 2`）
   - 资源增减只在消耗行出现一次，desc 不重复账本
9. **命名黑名单**（全库扫）：灭世|弑神|虚空|血怒|屠戮|金身|不动如山|百裂|气功|金刚|罗汉|内力|内息——西幻风，拒武侠/佛教/网文词；同一转职级别命名密度一致、不同层级不重名
10. 技能范围/reach：近战 reach=1（战士/刺客/拳师），远程 reach=2；技能自带 reach 仅超远程=3

## 六、子 agent 任务包（6 个，每个一条职业线）

### 每个子 agent 的固定上下文
- 职业线 = 基础职业 + 攻线 + 守线 + 隐藏线（全部相关转职线）
- 现有技能全量清单（见四、数据来源 skills.py/classes.py/core_resources.py）
- 核心资源定义 + 可复用机制库（第四节）
- 数值铁律（第五节）
- 设计方向主张（第三节对应条）
- 交付格式（本节下）

### 每线交付物（写文件到 workspace/v129_design/<线>.md）
1. **特色策略循环设计**：一句话循环 + 渐强/爆发/平稳定位 + 循环怎么转（决策点）
2. **完整技能组表**：每技能 = 汉名 / lv / 消耗(魔力+资源) / power / kind / element / 机制字段(cond/mech/aoe/cc/effect/team/passive/charge/派生) / desc 文案（符合显示规范）/ 等效威力计算
   - 基础职业 1-30：4 伤害主轴 + 5 辅助/机制 + 30 级终极奥义（三形态标准）
   - 分支 tier1(32)/tier2(60)/tier3(90)：每条分支 3~8 技能
   - 隐藏线 40/60/90：每条 2~4 技能（隐藏线技能数可少但机制要独特）
3. **数值合理性自检**：转职必变强验证（分支32vs基础30）/ 无零消耗技能 / 命名黑名单自查 / SKILL_UP 覆盖率 / 团队技能存在
4. **物品/装备联动提案**：新增词条/套装/道具联动（可选，写清楚"新增机制"还是"复用现有"）
5. **职业线改动说明**：改了什么定位/资源/分支，理由是什么（配合鱼鱼授权）
