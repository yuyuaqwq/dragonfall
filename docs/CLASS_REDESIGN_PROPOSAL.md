# 职业体系重构提案 · 从零设计

> 不考虑现有职业、转职机制、技能机制。这是一份完整替代品。
> 若只想要增量改造，请配合 `SKILL_TABLE_v142_REVIEW.md` 使用；本文件是**另一条路**。

---

## 〇、诊断：旧体系真正的病

不是数值失衡，不是文案虚标——那些是症状。病是这一条：

> **12 个职业 = 12 条私有资源条 + 12 套「攒点 → 放大」循环。**

怒气、气、禅意、连击点、猎印、影步、充能、时之沙、悼咏、龙力、精力、信仰值——十二个名字，同一个动作。玩家在战士身上做的事和在淬势者身上做的事，抽象后完全一致：用 A 攒 B，B 满了按 C。

后果有三：

1. **职业区分度是文案级的，不是操作级的。** 换职业不改变玩家手上的决策类型。
2. **团队配合没有共同语言。** 每个人经营自己的私有条，队友之间只能互相加数值，无法围绕同一件事协作。
3. **内容量线性膨胀。** 12 职业 × 3 档 = 36 套分支，每套都要单独设计、单独平衡、单独维护。而这 36 套又因为同构，做出来也不像 36 种体验。

---

## 一、新命题

> **职业不拥有资源。职业拥有「改变战场规则的权利」。**

具体化为三条：

1. **战场状态是全队共享的，且只有两套**（破绽条 + 气势）。没有任何一条资源是某个职业私有的。
2. **每个职业由它的动词定义**——它在战场上改变什么东西。八个动词互相正交，因此八个职业天然不撞车。
3. **每个职业必须付出一个会咬人的代价**。不是「消耗 3 点资源」这种无感扣除，而是真正限制你、甚至伤害你的东西。没有代价的职业是一条没有摩擦的斜坡，玩三回合就腻。

---

## 二、公共层：全队共享的四件东西

### 2.1 破绽条（Opening）——每个敌人 0 → 100

- 友方攻击按技能标注的量填充，与伤害无关。**打得不疼也可以填得很快。**
- 每回合自然衰减 **15**。这是节奏的来源：你必须持续施压，不能攒着等大招。
- 填满 → 该敌人进入【破绽】状态 1 回合：受到伤害 **+50%**，且本回合行动被推迟到最后。
- 衰减设计保证了「填充效率」和「填充总量」是两个不同的职业价值维度。

### 2.2 连携（Chain）——破绽的奖励

- 当**任何**友方攻击命中处于【破绽】状态的敌人，立刻触发一次**免费追击**（施放者自己的连携技，不消耗行动）。
- **追击不再触发追击**（防连锁爆炸）。
- 这是把「集火同一个目标」变成有回报行为的机制。全队第一次有了共同目标。

### 2.3 气势（Momentum）——全队共享 0 → 10

- 获取：暴击 +1、闪避 +1、击杀 +2。
- 失去：被暴击 -1、队友倒地 -3。
- 消耗方式**每个职业不同**（见第三章）。这产生了队内资源竞争——一回合只有那么多气势，给谁花？
- 部分职业可以把气势**转给**队友（调度型价值）。

### 2.4 站位 + 倒地

- 三排：**前排**（承受 70% 敌方单体攻击）/ **中排**（双方都能打，最危险也最适合某些技能）/ **后排**（敌方 AOE 优先命中）。
- **倒地 ≠ 死亡**：生命归零进入倒地，队友花一回合可扶起（恢复到 30% 生命）。全队倒地才算灭团。
  → 这条把「复活」从一个逆天技能降级为一个合理的战术动作，同时让战斗的失败过程有了层次。

### 循环

```
友方攻击 ──填充──> 破绽条满 ──> 【破绽】状态
                                    │
                              命中即触发
                                    ↓
                              连携免费追击
                                    │
                            暴击 / 击杀
                                    ↓
                                气势 +1/+2
                                    │
                        各职业花法（不同消耗方式）
                                    │
                                    └──> 回到填充
```

## 三、八职业：八个动词

不再按「坦克 / 输出 / 治疗」划分，按**你在战场上改变什么**划分。

---

### 1. 缄默骑士 · 承担

> 它不改变自己的数值，它改变**敌人打谁**。

| 技能 | 效果 |
|---|---|
| 立誓 | 指定一名队友，本场其受到伤害的 50% 转移给你。可改誓约对象，但改誓需要 1 回合 |
| 担 | 主动承受一次即将命中队友的负面状态 |
| 记账 | 承担的伤害累积为【债】；每点债使防御 +1%、速度 -1% |
| 清算 | 消耗 5 气势：把全部【债】转化为全队治疗（每点债 = 已承担伤害的 20%） |

- **连携技**：对攻击者填充 15 破绽（「你打错人了」）。
- **代价**：债越高越硬但越慢。它真的跪不下去，但也站不起来——高债状态下它无法被治疗以外的手段解救。
- **定位**：承伤 / 保护。与「嘲讽」的本质区别：嘲讽强制敌人，立誓是**主动选择**，因此可以被玩家玩出花（比如把誓约给故意卖血的铁誓佣兵）。

---

### 2. 灰烬术士 · 腐蚀

> 它不追求单次大伤害，它追求**让伤害持续生效并互相叠加**。

| 技能 | 效果 |
|---|---|
| 落烬 | 施加一层余烬。**可无限叠加**，第 n 层伤害 = 基础 × (1/√n) |
| 复燃 | 目标身上余烬层数 +50%（加速铺垫，跳过低效期） |
| 引爆 | 消耗全部余烬，立即结算剩余总伤害 ×1.5 |

- **连携技**：引爆后目标重新获得一半层数（二次引爆的铺垫）。
- **代价**：场上每有一层余烬（包括敌人身上的），它自己每回合损失 0.5% 最大生命。铺得越厚，烧得越快。
- **定位**：持续输出 / 延时爆发。全游戏最高的理论单次爆发，代价是 4–5 回合铺垫和持续自伤。

---

### 3. 织时者 · 重排

> 它改变**行动顺序**。

| 技能 | 效果 |
|---|---|
| 提前 | 使一名队友的下次行动立即发生（插入当前位置） |
| 延后 | 使一名敌人的下次行动推后 2 个位置 |
| 重演 | 使一名队友本次行动的结果再发生一次（60%） |
| 回环（终极） | 重复上一回合全场的行动序列——**友方重放，敌方也重放** |

- **连携技**：使目标的下次行动推后 1 位。
- **代价**：**它永远最后一个行动**。所有技能都在别人之后生效，因此它无法救场、无法打断、只能预判。
- **定位**：控制 / 调度。纯功能位，破绽填充极低，但它能让输出职业在一回合内多填一次。

---

### 4. 兽径猎人 · 划定

> 它改变**哪些敌人算作一组**。

| 技能 | 效果 |
|---|---|
| 划线 | 指定两个敌人，连接其间的所有单位；友方攻击命中其中任一时，其余承受 60% 伤害 |
| 孤立 | 指定一个敌人：不能被治疗/增益，也不能治疗/增益他人，持续 2 回合 |
| 拖拽 | 改变一个敌人的站位（前 ↔ 中 ↔ 后） |
| 合围 | 标记 3 个敌人为一组，对其中任一的暴击对其他两个造成 30% 伤害 |

- **连携技**：划线时沿线每个目标 +15 破绽（全职业最强的群体填充）。
- **代价**：**单体伤害全职业最低**。它的价值是把队友的 AOE 变成单体爆发，或把单体技能变成 AOE——自己不打人。
- **定位**：群体输出 / 阵型。它的强度完全取决于队友的配合意愿。

---

### 5. 白骨书记官 · 记录

> 它改变**什么算发生过**。

| 技能 | 效果 |
|---|---|
| 录·伤 | 记录本回合全队造成的伤害总量 |
| 录·治 | 记录本回合全队受到的治疗总量 |
| 回放·伤 | 将记录值的 40% 再次施加给当前目标 |
| 回放·治 | 将记录值的 80% 再次施加给全队 |
| 复写 | 使一名倒地队友回到其倒地前 1 回合的状态（HP / 增益 / 站位全部还原） |

- **连携技**：无（它是纯反应型职业，破绽贡献为 0）。
- **代价**：每次使用【录】类技能，本场战斗中**随机封印一个已学技能，不可解除**。用得越多，手段越少。
- **定位**：治疗 / 反应。「复写」不是回满血，是回到倒地前那一刻——如果那时状态很糟，复活毫无意义。这让复活从「逆天改命」变成一个需要判断时机的技术动作。

---

### 6. 铁誓佣兵 · 交换

> 它改变**什么值多少钱**。

| 技能 | 效果 |
|---|---|
| 典当·力 | 押上 50% 防御，换取攻击 ×2，持续 3 回合 |
| 典当·速 | 押上 30% 最大生命，立即行动一次 |
| 典当·命 | 押上 20% 最大生命，本回合免疫一次致命伤害 |
| 签约 | 与一名敌人签订：给予它 20% 我的最大生命，其本回合不攻击我的队友 |

- **连携技**：随机履行一份未到期的契（提前结算）。
- **伤害随已签订契约数量线性增长**（每份 +15%）。它是最强的后期 carry，前提是你敢签。
- **代价**：契约**到期必须履约**，还不上就永久失去被押出去的那部分属性。「签约」是全场唯一的**谈判**机制。
- **定位**：爆发 carry / 风险位。

---

### 7. 回声歌者 · 重复

> 它改变**一个动作的份数**。

| 技能 | 效果 |
|---|---|
| 回声 | 在一名队友行动后，复制该行动的 60%（伤害 / 治疗 / 增益均可） |
| 储存 | 本回合不复制，下回合可复制两次 |
| 轮唱（终极） | 本回合所有队友行动均被复制 60%，且复制可再次被复制（60% → 36% → 21.6%…） |

- **连携技**：复制连携追击。
- **代价**：**复制行动也复制其代价**。复制一个自残技能，它跟着自残；复制一个消耗生命的技能，它一起消耗。
- **特色**：它本身几乎没有主动技能。**它的全部价值 = 它站在谁旁边。** 全游戏最依赖队友配置的职业。
- **定位**：增幅 / 放大器。

---

### 8. 铸形师 · 创造

> 它改变**战场上有什么**。

| 技能 | 效果 |
|---|---|
| 墙 | 放置阻挡物，吸收一次敌方单体攻击 |
| 阱 | 放置陷阱，敌人行动时触发（伤害 + 填充 20 破绽） |
| 灯 | 照亮一个区域，友方对被照亮目标暴击 +15% |
| 锚 | 固定一个目标的站位，其不能被移动 |

- **连携技**：敌人攻击造物时，该敌人填充 20 破绽（「你打我的墙，你的侧身露出来了」）。
- **代价**：同时最多存在 **3 个**造物，放置第 4 个会摧毁最早的那个。它必须不断做取舍。
- **软嘲讽**：造物有独立的破绽条，敌人可以选择打造物而不是打人——这是它唯一的「吸引仇恨」形式，且是敌人主动的选择。
- **定位**：控场 / 防御。

## 四、进阶：不是转职，是誓约

### 4.1 为什么取消转职

旧体系 30/60/90 三次转职，36 套分支内容。问题：

- 转职后基础职业的内容被抛弃（学习成本沉没）。
- 36 套分支是**线性工作量**，每套都要单独设计、平衡、维护。
- 因为同构，36 套做出来也不像 36 种体验。

### 4.2 誓约（Oath）

- **没有转职。** 每个职业在 **20 / 40 / 60 / 80** 级各获得一次选择，从解锁的誓约卡中选 1 张，**不可重复、不可撤销**。
- 誓约卡**跨职业通用**——铁誓佣兵和织时者选的是同一批卡，但因为职业动词不同，同一张卡在两者手上是完全不同的东西。
- 最终卡池 12 张 → C(12,4) = **495 种组合**；× 8 职业 = **3960 种 build**。

**内容量对比：**

| | 内容份数 | 可得 build |
|---|---:|---:|
| 旧体系（12 职业 × 3 档） | 36 套分支 | 36 |
| 新体系（8 职业 + 12 誓约） | **20 份** | **3960** |

而且誓约卡可以随版本持续新增——**加一张卡 = 全职业同时获得新玩法**，不需要动任何一个职业本体。这是长期运营上最大的效率差异。

### 4.3 卡池（8 张基础 + 4 张隐藏）

**基础卡**

| 誓约 | 效果 |
|---|---|
| 血之誓约 | 技能改为消耗生命（替代魔力），伤害 +20% |
| 迅之誓约 | 行动提前 30%，伤害 -15% |
| 孤之誓约 | 每有一名队友倒地，全属性 +25% |
| 静之誓约 | 无法暴击；每次攻击必定额外填充 8 破绽 |
| 厚之誓约 | 最大生命 +40%，速度 -20% |
| 锐之誓约 | 暴击伤害 +50%，受到伤害 +20% |
| 续之誓约 | 每回合恢复 5% 最大生命；破绽填充效率 -30% |
| 契之誓约 | 破绽填充效率 +50%；每次填充时自身受到 2% 最大生命反噬 |

**隐藏卡（任务链解锁，全部双刃）**

| 誓约 | 效果 |
|---|---|
| 焚身之誓约 | 每回合开始损失 5% 最大生命；破绽填充效率 ×2，且目标进入破绽时你可额外行动一次 |
| 空之誓约 | 所有技能不消耗资源；每场战斗技能使用次数上限 = 等级 / 10 |
| 镜之誓约 | 受到的伤害 50% 反射给来源；你也无法被治疗 |
| 忘之誓约 | 免疫所有誓约的负面效果；作为交换，你也无法从队友的增益中获益 |

**设计要点**：每张卡都是**取舍**，不是纯增益。玩家不是在「选最强」，是在「选我想承担哪种代价」。最后一张「忘之誓约」是反协同卡——它让某个职业彻底脱离团队体系，适合独狼 build。

## 五、数值哲学：把倍率拍平

### 5.1 问题

现有体系的 100%–650% 倍率是个陷阱：

- 玩家无法感知 240% 与 260% 的区别，数字失去意义。
- 多段技天然优于单体技（5 段 × 130% = 650% > 终极技 500%），导致 build 单一化。
- 160 个倍率需要逐个平衡，且无法批量调整。

### 5.2 方案

**所有伤害技能的基准统一为 100（= 一次普通攻击）。**

技能之间的差异**不在倍率**，只在三个维度：

| 维度 | 取值 |
|---|---|
| **破绽填充量** | 5（轻击）/ 15（中击）/ 30（重击）/ 特殊值 |
| **附加规则** | 无视站位 / 必定暴击 / 触发连携 / 改变站位 / 多目标 / 阻断行动 |
| **代价** | 气势消耗 / 生命消耗 / 冷却回合 / 誓约条件 / 造物槽位 |

一个「大招」不是「400% 伤害」，而是：

> 造成 100 伤害，**填充 40 破绽**，且若目标已处于【破绽】状态，本次伤害必定暴击。

### 5.3 收益

1. **玩家能口算。** 所有技能都是 100 上下，一眼看出区别在机制而非数字。
2. **平衡只需调三张表**（填充量 / 附加规则 / 代价），不用调 160 个倍率。批量调整成为可能。
3. **多段技不再天然优势。** 段数只影响填充次数，不影响伤害基准。
4. **数值膨胀可控。** 基准恒为 100，成长来自机制利用率与破绽配合，而非数字本身。
5. **文案不会虚标。** 因为根本没有需要承诺的倍率——这直接消灭了旧体系「power 与文案两套口径」的问题。

## 六、敌人侧：让公共机制在 PvE 中有意义

如果 Boss 不参与破绽 / 气势系统，那这套公共层就只是玩家自娱自乐。Boss 必须能**反向操作**这些系统：

| 词条 | 效果 |
|---|---|
| 霸体 | 破绽条衰减加倍（30/回合），逼迫玩家提高填充密度 |
| 夺势 | 每次攻击偷取 1 点气势，直接掐断玩家的爆发节奏 |
| 清阵 | 每 3 回合清空自身破绽条，惩罚「慢慢攒」的打法 |
| 连体 | 两个 Boss 共享一条破绽条——填满任何一个都会让两个同时进入破绽 |
| 镜像 | 玩家每获得 1 点气势，Boss 也获得 1 点 |

这些词条让「填充破绽」从一个机械动作变成一个需要读 Boss 机制的博弈。

## 七、队伍组合：真实的取舍

4 人小队，因为破绽 / 气势是全队共享的，组队第一次有了真实的取舍：

1. **谁花气势？** 缄默骑士的【清算】要 5 点，铁誓佣兵的契约要 3 点，织时者的【重演】要 4 点——一回合只有那么多，给谁？
2. **集火谁的破绽条？** 是快速填满一个脆皮先秒掉，还是留着给灰烬术士的引爆窗口？
3. **回声歌者复制谁？** 取决于主 C 是谁，也取决于谁的技能代价是歌者承受得起的。
4. **兽径猎人的线画在哪？** 画错位置会让 AOE 打到不该打的目标（提前唤醒不该唤醒的敌人）。

**典型组合示例：**

- **卖血爆发队**：铁誓佣兵（主 C）+ 缄默骑士（立誓给佣兵，承接反噬）+ 回声歌者（复制佣兵的爆发）+ 白骨书记官（录下爆发伤害后回放）
- **腐蚀控制队**：灰烬术士 + 兽径猎人（划线让余烬铺满全场）+ 铸形师（阱 + 灯）+ 织时者（重演术士的引爆）
- **独狼队**：铁誓佣兵（忘之誓约）+ 三个工具人倒地触发孤之誓约 → 极限单核

## 八、落地路径（如果要做）

| 阶段 | 内容 | 说明 |
|---|---|---|
| **1. 引擎层** | 破绽条 / 气势 / 连携 / 站位 / 倒地 | 五个公共机制。这一步做完，旧职业可以先挂上去跑通 |
| **2. 数值层** | 把伤害基准拍平到 100 | 可渐进：先新增技能按新标准写，旧技能分批迁移 |
| **3. 职业层** | 8 个新职业 | 可先做 4 个（骑士 / 术士 / 猎人 / 佣兵）验证手感，再补 4 个 |
| **4. 誓约层** | 8 张基础卡 | 先上基础卡，隐藏卡随版本节奏放 |
| **5. 敌人层** | Boss 词条 | 与阶段 1 同步设计即可 |

**兼容性**：阶段 1 和 2 是**纯增量**，不破坏现有职业。即使最终决定不做新职业，这两步也能立刻解决旧体系「团队配合没有共同语言」和「倍率虚标」两个问题。

## 九、这套设计放弃了什么

诚实地说，有三个代价：

1. **玩家的「资源条」没了。** 很多人就是喜欢看自己的能量条涨满然后爆发。这套设计里没有个人资源条，爽感来源从「攒满」变成「打配合」。这是一次口味赌博。
2. **8 个职业比 12 个少。** 职业数量是玩家感知的「内容量」指标之一，8 个看起来比 12 个单薄（虽然 build 数是 100 倍）。
3. **学习曲线前移。** 破绽 / 气势 / 连携三条公共规则必须在开局就讲清楚，否则玩家前 10 级会懵。旧体系的「每个职业自己一条小资源」反而更容易各自上手。

如果这三条里有不能接受的，最省事的折中是：**保留 12 个职业，但把它们的资源换成破绽 / 气势两个公共池**——阶段 1 单独上，一样能拿到大部分收益。
