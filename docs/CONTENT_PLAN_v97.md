### 0.2 核心机制新增（本次工程的地基）
1. **告示委托系统**：告示板从"纯文案"升级为"可撕取委托"——交互时展示委托单，接取后写入玩家 quests，

3. **稀有刷新标记**：怪物/精英支持 `rare: true` 低概率替换普通怪，带专属掉落。
4. **世界事件轮盘**：低概率全服事件（月食/流星雨/集市日），带时效 buff/场景变化。
5. **时段系统**：白天/黑夜影响部分事件与 NPC（已有 采药女 白天窗口先例，系统化）。

## 一、阶段一：告示委托系统 + 条件探索事件（机制地基，先实现）

### 1.1 机制说明
- 每个城镇的**告示板 props** 交互时：60% 展示普通公告文案；40% 出现"委托单"（每条委托一次，完成后撤下）。
- 委托单显示：标题 + 悬赏 + 线索（地图暗示）。玩家输入『接取委托』（或交互时直接给选项）后写入任务。
- 委托任务使用新 objective 类型 `find`：在指定地图**探索时有概率触发条件事件**（找到目标），
  触发后任务自动完成/获得任务道具，回告示板所在地交付（或指定 NPC）。

### 1.3 条件探索事件引擎（实现细节）
- `EXPLORE_QUEST_EVENTS`：新事件表，条目含 `quest`（挂钩任务 id）+ `map`（限定地图）+ `chance`（触发概率）。
- 探索流程：常规事件 roll 前，先查玩家是否有进行中的 `find` 任务 → 命中地图 → 按 chance 触发条件事件。
- 触发后：任务推进到"交付"阶段（objective 状态更新），文案带目标物描述。
- 交付：回到发布地/指定 NPC，『交付』或对话触发，任务完成结算。

## 十二、风险与控制

1. **平衡性**：所有彩蛋奖励克制（数值不超过同级常规事件 1.5 倍）；稀有掉落只服务隐藏配方，不产生装备碾压。
2. **不重复性**：每条文案入库前查重（grep 名称/关键词）；同区域元素不重复设计。
3. **可发现性**：隐藏内容必须有线索（告示/对话/见闻提示），禁止无提示纯随机。
4. **性能**：条件事件检查为 O(进行中任务数)，可忽略。
5. **测试**：每个阶段配单测（触发条件/流程/奖励结算）；全量回归兜底。
