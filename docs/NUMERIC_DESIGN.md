## 一、数值体系总览

### 1. 怪物数值（core/stats.py + data/stat_templates.py）

```
monster_stats(lv, role)：
  stats = MONSTER_ROLE_BASE[role] + MONSTER_ROLE_GROWTH[role] × (lv-1)
  boss 角色：  hp × (1 + lv × 0.06)        ← boss 专有血量系数（随等级膨胀！）
  elite 角色： hp × (1 + lv × 0.04)
  全体：       hp × hp_stage_mult(lv)      ← 等级段放大（加速曲线）
               atk × atk_stage_mult(lv)    ← 后期放缓（减速曲线）

hp_stage_mult：Lv≤30: 1.0+(lv-15)×0.08 ｜ Lv≤60: 2.2+(lv-30)×0.04 ｜ 之后: 3.4+(lv-60)×0.03
atk_stage_mult：Lv≤30: 1.0 ｜ Lv≤60: 1.0-(lv-30)×0.005 ｜ 之后: 0.85-(lv-60)×0.004
```

- 7 角色模板：tank(血牛) / dps(攻高) / caster(魔攻) / speedster(敏捷) / healer / elite(精英) / boss(首领)
- build_monster：个体修正走 `MONSTER_MODS[mid]`（同 role 同等级不同怪数值错开，含 mech 机制）
- **Lv.28 基准**（校准锚点）：dps≈450HP/ATK106 ｜ elite≈1175HP/ATK190 ｜ boss 模板≈1726HP → ×系数后 ≈9435HP

### 2. 玩家数值（engine.py + data/stat_templates.py）

```
player_final_stats = 职业基础属性（base+growth×lv，含转职 tier）
                   + 装备加成（equip_stats × 强化倍率）
                   + 自由属性点 + 称号 + 种族天赋
equip_stats(slot, lv, quality) = (EQUIP_SLOT_BASE + EQUIP_SLOT_SCALING × lv) × QUALITY[quality].mult
QUALITY mult：白1.0 / 绿1.3 / 蓝1.6 / 紫1.8 / 橙2.0
```

- 装备部位 7 个：weapon / helm / armor / legs / boots / ring / necklace
- 强化 ENHANCE_TABLE：+1~+9，属性 mult 1.1→2.62；**成功率 100%→3%（+5 后骤降）**；成本 50→8000 金；+5 起失败降 2 级
- 强化门槛：需强化副业学徒 + 副业 Lv.N（+N 需要副业 Lv.N）→ **Lv.20 级玩家实际可达 +3~+5**
- 附魔：蓝 1 孔 / 紫 2 孔 / 橙 2 孔（crit/dodge 微量）；符文（MC 式，独特效果）；套装（蓝+ 2件/4件）；称号；种族天赋（月缺 HP-5% 等）

### 3. 副本 Boss（data/instances.py）

```
Boss 定义 = 6 元组 (id, 名, role, lv, [技能], [掉落])
Boss HP（实例化） = build_monster(模板) × [hp_mult + 0.65 × (实际人数 - min_players)]
hp_mult 档位：单刷 1.6-1.8 ｜ 2-3 人 2.2-2.5 ｜ 4 人 2.7-3.0
```

### 4. 伤害公式（engine.py calc_damage）

```
dmg = atk² / (atk + def)   ← 非线性减伤（v22），防御收益递减、不免疫
浮动 ±15%，暴击 ×1.5，防御指令减半，词条/种族/符文追加乘区
```

## 三、设计意图（#282 审计还原）

当初的设计意图（从注释/结构还原）：

1. **等级段放大（hp_stage_mult）**：后期怪血量加速增长，保证"后期压迫感"——注释原文"保证后期 Boss 有压迫感"
2. **boss 专有系数 (1+lv×0.06)**：Boss 血量额外随等级膨胀，制造"首领感"
3. **hp_mult 人数补偿**：多人副本 Boss 血量随人数上涨（+0.65/人），组队不能白嫖
4. **强化成功率/成本曲线**：+5 后骤降 = 长线养成深度，强化毕业是"氪肝目标"

**问题**：意图合理，但三层血量乘数叠加后 Boss HP = 普通怪 **46 倍（Lv.28）~ 21 倍（Lv.100）**，远超"4-8 倍"的设计舒适区；且强化毕业（+9，成功率 3%/26 万金）在主线阶段（Lv.22，身上 ~2 万金）**不可达**——Boss 实际按"玩家达不到的状态"设计的。

## 五、未来扩展检查清单（加内容前必读）

### 加新副本
1. 副本 lv 与主线推进等级匹配（Boss Lv = 副本 Lv + 2~6）
2. 选 hp_mult 档位（人数档位对应表见上）
3. **跑 `scripts/numeric_calibration.py`**：Boss 战轮数必须落在 15-30 轮（按该等级玩家"蓝装+3~+5"档位算，不是毕业档！）
4. 组队弹性：min=1/max>1 时确认开本逻辑（已支持）

### 加新怪物/角色类型
1. MONSTER_ROLE_BASE + MONSTER_ROLE_GROWTH 各加一条（注意 hp/atk 比例参照现有 7 角色）
2. boss/elite 系数自动套用（新增角色类型注意不要误用）

### 加新装备部位/品质
1. EQUIP_SLOT_BASE/SCALING + QUALITY
2. 跑校准脚本验证对玩家输出的影响（别让新部位悄悄拉高输出导致 Boss 变弱鸡）

### 调强化/成功率
1. ENHANCE_TABLE 成本/成功率曲线保持连续性（+5 骤降是有意设计）
2. 强化毕业成本 vs 主线阶段金币量——**强化毕业必须晚于主线 Boss 需求**（现在正好反了，这是 #282 的教训）

### 任何数值变更后
1. 跑 `scripts/numeric_calibration.py` 看全副本轮数表
2. 跑对应测试（副本/战斗/装备）
3. 更新本文档（锚点/结论）

## 六、经济数值体系（v101.25e，2026-08-12 鱼鱼拍板）

> 背景：playtest 核算发现四失衡——商店装备太便宜（打 1 只怪买 1 件蓝装）、掉落推导价与商店价脱节 5-11 倍、强化成本与装备价倒挂、任务奖励金币寒酸（=1 只怪）。鱼鱼拍板：**装备要有经济重量 + 打怪/任务/商店三渠道价值统一**。

### 1. 装备价格体系

```
装备推导价（drops.py，掉落/锻造产物价值）：
  price = equip_value(装备属性) × (3 + lv × 0.5) × QUALITY[quality].mult
  equip_value = 属性加权总值：atk/matk/def/mdef/spd/crit/dodge 全价，HP/MP 按 0.1 折算
  （v101.25h3 修复：HP 与攻击等价计价曾让权杖 hp_fix+60 的 Lv.2 白装卖 560 金币 vs 铁剑 80）

商店买入价（economy.py `_shop_equip_price`，v101.25e 前为 (8+lv×6)×mult）：
  price = 确定性推导价（含武器风味、不含随机词条） × 品质系数
  品质系数（v101.25h3 鱼鱼：差距调大，原白2.0/绿1.7/蓝1.5/紫1.3/橙1.2 递减抵消属性倍率，
  最终橙/白只差 1.2 倍 → 改递增）：白 2.0 / 绿 2.4 / 蓝 3.0 / 紫 4.0 / 橙 5.5
  最终价格比（属性倍率×系数）：白 1.0 / 绿 1.9 / 蓝 3.7 / 紫 6.4 / 橙 11.0
  显示价与购买价同源（同一函数），防词条随机导致价格漂移

装备回收价（economy.py `_sell_one`，v101.25e）：
  掉落装备卖商店 = 推导价 × 0.3（固定，不分设施；v101.21 前为 0.8~0.9）
  商店购入装备再卖 = 买入价半价 × 0.3（防刷钱，v21 规则保留）
```

**经济锚点（核算基准，v101.25h3 后）**：

| 等级 | 怪金/只(期望) | 白装商店价 | 蓝装商店价 | 白装≈几只怪 | 蓝装≈几只怪 |
|---|---|---|---|---|---|
| Lv.3 | ~75 | 108 | 387 | 1.4 | 5.2 |
| Lv.15 | ~155 | 756 | 2823 | 4.9 | 18.2 |
| Lv.25 | ~253 | 1736 | 6549 | 6.9 | 25.9 |
| Lv.40 | ~411 | 3956 | 15018 | 9.6 | 36.5 |

设计意图：**白装 5~10 只怪**（新手期白装 1~2 只怪友好起步），**品质价格梯度拉开**（蓝装 ≈ 白装 3.7 倍价格、橙装 ≈ 11 倍——高品质是长线目标不是随手可买）；强化 +9（5000 金）≈ 20 只怪，强化成为装备之上的长线投资。⚠️ 蓝装 18~36 只怪略偏贵（v101.25h3 新系数首版），观察 playtest 反馈再微调。

### 2. 商店等级断层补档（#298 修复）

```
_shop_equip_roster(player, 静态配置) = 静态 ∪ 动态补档
  动态补档：EQUIP_ROSTER 中 source="商店" 且 |装备lv - 玩家lv| ≤ 2 的名册装备，按接近度取前 2 件
```

设计意图：静态城镇配置（白鹿 Lv.3-5 → 铁港 Lv.12-16 → 王都 Lv.28-32）存在 6-13/15-27 级断层，动态补档保证**每个等级都有装备可买**，同时不破坏城镇特色配置。

### 3. 任务奖励金币（v101.25e 调整）

```
MAIN_QUESTS + SIDE_QUESTS 全部 reward_gold ×5（124 处；DAILY_QUESTS 不动）
示例：q1_1 初出茅庐 30→150 ｜ q3_3 海盗王·独眼杰克 500→2500
```

设计意图：任务不再是"1 只怪的钱"，前中期任务 150-400 金 ≈ 2-5 只怪，任务链成为装备资金的重要来源。**任务不给装备**（鱼鱼拍板：正常给金币就好）。
