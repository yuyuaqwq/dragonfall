## 一、需求拆解（鱼鱼原话 + 澄清拍板）

1. **商店限购机制（数据驱动）**
   - 每种商品：`总库存上限` + `每人每日限购` + `补货时间配置`，全数据驱动
   - 覆盖：商店消耗品（食物/药水/卷轴/符箓/强化石/双倍金币符…）、材料、装备
   - 澄清拍板：
     - **总库存按子区域（店铺）独立一份；同一家店内的库存是全体玩家共享扣减**（先到先得，
       店与店之间独立）。铁匠铺同样：每家铁匠铺独立库存，店内多玩家共享。⚠️ 不是"每人独立一份库存"。
     - 每人每日限购 = 叠加在共享库存之上的第二层（防单人扫光店铺共享货）
     - 铁匠铺货架从"全服共享一份（key 无店铺）"改为"每子区域独立一份（key 带店铺）"
     - 限购范围：**每商品可配置**——重点商品（buff/强化石/高级药水/双倍金币符/装备）配额度，
       普通小药/基础食物可不配（不限）防误伤新手
     - 装备（SHOP_WEAPONS 武器/名册防具）也纳入

2. **商店物品价格 / 经济合理性检查 + 数值门禁**
   - 用 economy_lib 体检商店商品定价是否合理（对照产出侧：玩家打怪收入 vs 商品价）
   - 新增数值门禁：商店商品价格合理性（若必要）

3. **代工去图纸（只代工）**
   - 澄清拍板：**代工 = 材料 + 3倍金币直出**，免图纸、免副业等级
   - **自己『锻造』保留图纸 + 副业等级**（图纸线保留：v135 图纸掉率/残页合成仍有效）
   - 重新检查每个装备对应阶段、配方材料、获取途径、经济是否合理
   - 开多个子 agent 分析

4. **分析每个阶段装备是否足够丰富**
   - 装备名册 632 件按阶段（E1-E6 / 城镇等级带）分布审计
   - 每个阶段各部位（武器各类型/防具/首饰）覆盖度

## 三、方案

### A. 商店限购（新增数据层 shop_limit + core/shop_stock 重构）
- 数据：每个商品条目（消耗品/材料/装备）可配：
  ```
  limit: {stock: N, per_day: M, restock: {"every_hours": H} 或 {"at": "04:00", "every_hours": H}}
  ```
  配在商品级（物品全局一份配置），作用于每个上架该商品的子区域（各店独立库存）
- 存储两层（event_state KV）：
  - **共享库存层**：key `shop_stock_{sa_id}_{iid}`，JSON `{stock_left, restock_at, day}`——
    店内所有玩家共享扣减，读时惰性补货/换日（与 smith_stock 同款）
  - **个人每日限购层**：key `shop_daylimit_{gid}_{qid}_{iid}` 或汇总 `shop_daylimit_{gid}_{qid}`
    JSON `{date: "2026-09-02", bought: n}`——每人每自然日在该店该商品最多 per_day 件，
    跨天清 0（放个人侧，避免每店每商品都全服扫一遍玩家）
- 铁匠铺货架 v135 重构：`smith_stock_{map_id}` 全局 key → `smith_stock_{sa_id}`（各子区域独立）
  - 但注意 v135 测试/策划案写"全服共享先到先得"——改为子区域独立需同步策划案 10 章 + 32 章
- 装备：SHOP_EQUIP/SHOP_WEAPONS 也配限购（哪几件配？数据驱动，可配）

### B. 价格检查 + 数值门禁
- economy_lib 增加 shop_scan：商店商品定价 vs 该阶段产出（per_kill_gold 折算）
  健康带参照：单件补给 ≈ 该阶段 N 只怪（药水 0.5-2 只、buff 3-8 只、卷轴 5-10 只等）
- 检查后把定价偏离严重的商品调价（只调数据，进 MATERIAL/ITEMS price 或覆盖表）
- 新增 test_numeric_shop_pricing.py 门禁

### C. 代工去图纸 + 配方阶段审查（多子 agent）
- craft_commission 改：去掉图纸检查（learned_blueprints 不再拦截），只保留材料 + 3倍金 + 等级校验（lv 上限保留？）
- 文案同步：代工帮助文字从"图纸+材料+3倍金"→"材料+3倍金"
- 需检查：craft_recipe_make 对无蓝图配方产物（原本只能锻造的，现在代工也能直出？）
  —— 设计上：代工=不学图纸也能用材料请 NPC 做（3倍金溢价 = 图纸机会成本替代）
- 配方经济：现有 352 配方成本占比已 v165 校准，但代工 3 倍金后要复查
- 装备各阶段丰富度分析（子 agent 并行）：
  - E1-E6 每阶段名册覆盖（武器各类型×部位×品质）
