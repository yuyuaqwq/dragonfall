## 五、v175e 真引擎多段伤害 bug 修复（鱼鱼质疑"真引擎有没有连段 bug"——确认有！）

### 5.1 Bug 确认
- `game/battle.py:4522` 读 `info.get("multi", 1)` 作为技能段数
- 但**全库技能数据统一用 `hits` 键**（无任何 multi 键）→ multi 恒=1 → **22 个多段技能全部只打 1 段**
- 涉及：疾风连射(2段)/急速射击(4段)/怒涛终焉(4段)/奥术弹幕(3段)/幻影连刺(3段)/连招三连(3段)等 7 职业 22 技能
- **期望引擎 numeric_lib/player.py 一直读 hits 正确** → 真引擎伤害系统性低于设计值（多段流只有 1/N 伤害）

### 5.2 修复
```python
multi = int(info.get("multi") or info.get("hits") or 1)   # hits 为主，multi 旧别名兼容
```
实测：连射单发 1段384 → **2段548（+43%）**，日志正确显示"连击 2 次"
- commands/player.py 技能详情"连击 xN"显示同步修复
- 敌方技能（205个）无 hits → 不受影响
