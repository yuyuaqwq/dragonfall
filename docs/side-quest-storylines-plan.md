# 支线剧情线扩容计划（v124 设计阶段）

## 背景
- 现状：45 条支线全部单步（接→杀/捡/探→交），0 条链式，story 钩子不收束；214 个 NPC 中剧情 NPC 偏少。
- 目标：把支线改造成"剧情线"体系——多条 3-6 步的链式支线，前置解锁推进，剧情经对话树展开；新增生活线与主题线；每条线配专属剧情 NPC。
- 本阶段只做**设计**（策划案 06 章扩容），代码落地（SIDE_QUESTS chain 字段+状态机复用）在鱼鱼审稿后另起。

## 子 agent 输入（必须读的策划案章节）
- `design/new_world/01_世界观与背景.md`（世界观+名词黑名单）
- `design/new_world/02_地图系统.md`（地图/子区域名，文案地名必须一致）
- `design/new_world/03_NPC群像.md`（NPC 命名/头衔风格）
- `design/new_world/06_支线与委托.md`（现有支线表，串入时保留原 id）
- 奖励梯度参考：同档支线金币/经验（06 章现表），禁止倒挂

## 输出格式（每个 agent 写一个 md 到 side_quest_designs/）
1. 线名/主题/玩家等级段/总步数
2. 任务链步骤表：step id、名称、giver、地点（子区域名必须来自 02 章）、objective（仅 kill/collect/explore/find/use 五类）、前置解锁（上一步完成 or 主线某节）、奖励（经验/金币/物品，金币按同档梯度，不准×5 通胀）
3. 每步剧情三段式：接取台词 / 推进台词（对话树节点）/ 交付台词
4. 新增 NPC 定义：id（npc_ 前缀）、姓名、头衔、map、icon、funcs、dialogue、lore
5. 策划案 06 章新增章节文本（markdown，格式与现章一致）
6. 奖励物品清单：已有物品用现名，新物品须标注类型（消耗品/材料/图纸/称号）

## 设计铁律
- 文案西幻风：禁用武侠/佛教/网文黑名单词（灭世/弑神/虚空/血怒/屠戮/金身/不动如山/百裂/气功/金刚/罗汉/内力/内息）
- NPC 名西方奇幻风格（参考 03 章），不抄现实人名/游戏名
- 地名一律用 02 章实际子区域名，新地名必须标注"需新增"
- objective 只用现有五类机制，不设计新机制（设计阶段不碰代码）
- 每步任务必须可独立完成，链式靠前置解锁不靠隐藏状态
- 奖励金币：Lv.2-10 ≈ 60-250，Lv.30 ≈ 700-1200，Lv.50 ≈ 1500-3000，Lv.70+ ≈ 4000-8000（参考 06 章校准值）
- 每线 1-3 个新 NPC，全游戏新增 NPC 总量控制在 20 个内
- 每条线总步数 3-6 步（含串入的现有支线），单线新增任务 ≤4 个

## 验收
- 10 个设计稿齐全，无黑名单词，奖励梯度合规，地名可查
- 主 agent 汇总 → 合并进 06 章 → 鱼鱼审稿 → 代码落地
