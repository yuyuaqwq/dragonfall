## 一、背景与目标

### 1.1 现状问题

1. **伤害类型只挂在技能上**：技能数据有 `kind`（物理/魔法），但普攻、反伤、dot、词条附加伤害等散落为裸逻辑，没有统一伤害类型概念。
2. **真伤缺失**：pierce（无视防御）是唯一"穿透"手段，但 pierce 仍吃物免/魔免/格挡/元素抗，没有全无视减伤的伤害。
3. **召唤流派空白**：战斗为 1v1 单体回合制，无召唤物实体、无多段来源。
4. **隐藏职业仅 2 个**（吟游诗人/魔剑士），基础职业 6 个只有常规三转，缺少横向扩展。

### 1.2 目标

1. 建立**伤害类型四层架构**：类型（phys/magi/true）成为伤害事件一等公民，所有伤害来源声明类型。
2. 新增**召唤物系统**：独立战斗实体（自动攻击 + 挡刀 + 受击死亡 + 叠层）。
3. 扩展至 **13 个隐藏职业**：6 基础职业全覆盖 + 召唤两线（数量流/质量流）+ 真伤线。
4. 伤害类型与机制正交：暴击/斩杀/穿透/吸血/血魔法可挂任意类型。

## 二、伤害类型四层架构

### 2.1 第 1 层：伤害类型定义（dmg_type）

| 类型 | 标识 | 基数 | 结算链 | 吃穿透 | 触发吸血 |
|---|---|---|---|---|---|
| 物理 | `phys` | atk × power | vs def，吃物免 phys_reduce、格挡 block | 物穿 pene_phys | 物吸 lifesteal_phys |
| 魔法 | `magi` | matk × power | vs mdef，吃魔免 magic_reduce、元素抗 elem_res | 法穿 pene_magi | 法吸 lifesteal_magi |
| 真伤 | `true` | 数值 × power（低系数） | **绕过全部减伤**（防御公式/物免/魔免/格挡/元素抗/深渊抗） | 无（本就无视） | **不吸血**（纯粹） |

真伤规则：
- 真伤可暴击（暴击为真伤基数 × 暴伤），但真伤技能 power 显著低于同级（约 0.6-0.8 倍率）。
- 真伤不触发吸血/格挡反伤（源头上不可转化）。
- 真伤来源为技能字段 `true_dmg: True` 或词条/被动声明类型 true。

### 2.2 第 2 层：伤害来源清单（每个来源声明类型）

| 来源 | 默认类型 | 说明 |
|---|---|---|
| 普攻 | phys | 魔剑士附魔普攻 → magi（magic_add 现有雏形，改为显式类型段） |
| 技能 | kind 映射 | 物理→phys，魔法→magi，新增真伤→true |
| 反伤 thorns | phys | 举盾格挡/荆棘反伤为物理反伤 |
| 格挡反击 | phys | 与 block 联动 |
| 毒 dot | magi | 吃魔免，**不吃元素抗**（毒非元素） |
| 灼烧 dot | magi | 吃魔免 + 元素抗（火系） |
| 元素反应 | magi | 超载/感电等均为魔法段 |
| 词条附加伤害 | 跟随主伤害 | 流血/连击附加与主伤害同类型 |
| 真伤技能/词条 | true | 新字段显式声明 |

### 2.3 第 3 层：机制层（与类型正交）

| 机制 | 正交性规则 |
|---|---|
| 暴击 | 三类型均可暴；真伤可暴但基数低 |
| 斩杀 | <30% 血伤害加成，跟随伤害类型 |
| 穿透 | 只对对应类型生效（物穿→phys，法穿→magi），真伤无需穿透 |
| 吸血 | 按类型分流；真伤不吸血 |
| 血魔法 | 消耗 HP 换伤害加成，类型不变 |
| 毒爆/印记爆发 | 叠加类机制，爆发段类型跟随基础伤害 |

### 2.4 第 4 层：加成层（按类型分流）

- 词条/被动/种族分三类加成：`物理伤害+x%`、`魔法伤害+x%`、`真伤+x%`，只作用于对应类型。
- 现有 `passive_bonus`/`affix_mult` 为一锅炖乘算，**实施分期**：第一期结算链分流（伤害产出正确），第二期加成按类型分流（逐步迁移，避免一次性大爆炸）。

## 三、召唤物系统设计

### 3.1 实体模型

```python
summons = [  # battle 实例字段，初始 []
    {"id": "skeleton", "name": "骷髅兵", "hp": 80, "max_hp": 80,
     "atk": 20, "def": 8, "dmg_type": "phys", "turns": 0, "max_turns": 0}

```

### 3.2 行为规则

| 规则 | 说明 |
|---|---|
| 召唤 | 技能字段 `summon: "skeleton"`，按模板生成实体；上限：亡灵系 3 个，兽王系 1 个（进化形态） |
| 自动攻击 | 玩家行动结算完毕后，每个召唤物自动攻击一次（伤害走 dmg_type 结算链，吃玩家召唤强化加成） |
| 挡刀 | 敌人攻击时，x% 概率由随机存活召唤物承受（受伤转移，伤害按召唤物 def 结算）；概率可被技能强化 |
| 受击死亡 | 召唤物 hp ≤ 0 消失，日志提示；重新召唤需技能冷却 |
| 存活回合 | 可选 `max_turns`（永久型为 0 不限）；时间型到期消散 |
| 强化 | 召唤强化属性（`summon_power`）：+atk/+hp/挡刀率，来源=职业技能/被动/词条 |

### 4.2 设计逻辑

- **6 基础职业全覆盖**：战士→龙血战士；法师→奥术师/血法师；游侠→占星者/丛林猎手/兽王；牧师→圣殿骑士/亡灵术士；刺客→影武者；拳师→武圣。
- **召唤两线区分**：亡灵术士=数量流（3 骷髅自动攻击 + 挡刀 + 牺牲替死）；兽王=质量流（1 宠进化形态，宠强人弱）。
- **新机制 8 个**：真伤、斩杀、吸MP、毒爆、格挡反击、反击、血魔法、召唤（含死亡契约）。
- **解锁统一**：Lv.40+ 各职业专属任务链（同吟游/魔剑传承式），NPC 引导。

### 4.3 各职业详案（简版）

#### 🔮 奥术师（法师线）
- 专属：pene_magi 15% + arcane 强化
- 机制：奥术印记（技能命中叠印记，印记层数 ≥3 时奥术爆发：层数×系数追加魔法伤害）
- 技能示例：奥术飞弹（叠印）、奥术脉冲（爆发）、秘法护盾（护盾强度联动）

#### 🗡️ 影武者（刺客线）
- 专属：pene_phys 15% + crit_dmg 20%
- 机制：斩杀（目标 HP<30% 时伤害 +40%，斩杀线随技能等级提升）
- 技能示例：影袭（满血必暴，已有 shadow 机制）、残血追猎（斩杀被动）、暗影步（闪避）

#### 🐉 龙血战士（战士线）
- 专属：elem_res 15% + 火系强化
- 机制：真伤（龙息技能 true_dmg: True，power 0.7）+ burn 灼烧
- 技能示例：龙息（真伤+灼烧）、龙鳞（元素抗提升）、龙威（降敌攻）

#### 🌑 虚空行者（任意线）
- 专属：abyss_res 15%
- 机制：吸MP（魔法伤害的 15% 回复自身 MP）+ 暗影强化（shadow 机制加成）
- 技能示例：虚空箭（吸MP）、深渊凝视（降敌魔防）、虚空行走（闪避+回蓝）

#### ⭐ 占星者（游侠线）
- 专属：luck 15%
- 机制：运势（幸运转化为暴击率补充 + 暴击时 30% 概率追加一次 50% 伤害）
- 技能示例：星陨（暴击强化）、占卜（buff 幸运）、命运之轮（随机多段）

#### 🌿 丛林猎手（游侠线）
- 专属：毒系强化（毒层伤害 +20%）
- 机制：毒爆（poison 层数 ≥3 可主动引爆：层数×系数伤害，清层）
- 技能示例：毒箭（叠毒）、藤蔓缠绕（减速+毒）、毒爆术（引爆）

#### 🛡️ 圣殿骑士（牧师线）
- 专属：shield_power 15% + block 10%
- 机制：格挡反击（格挡成功时 x% 概率对攻击者造成格挡值×系数物理伤害）
- 技能示例：圣盾（护盾）、壁垒（格挡提升）、圣光审判（魔法输出）

#### 🥊 武圣（拳师线）
- 专属：连击强化（combo 三连追加 0.30→0.50）
- 机制：反击（受击时 20% 概率立即普攻反击一次）
- 技能示例：以守为攻（反击提升）、气劲连打（连击）、铁山靠（反击强化）

#### 🧛 血法师（法师线）
- 专属：lifesteal_magi 15%
- 机制：血魔法（技能可声明 hp_cost：消耗当前 HP 10%，伤害 +30%）
- 技能示例：血之契约（hp_cost 高伤）、猩红汲取（法吸强化）、血盾（护盾）

#### 💀 亡灵术士（牧师线）

## 五、数值平衡原则

1. **真伤保守**：power 0.6-0.8（同级普通技能 1.0），因绕过全减伤，DPS 曲线后期上仰但前期持平。
2. **召唤物弱于本体**：召唤物单体输出约为玩家普攻 60-70%，优势在"多段 + 挡刀生存"，不碾压单体爆发。
3. **隐藏职业属性**：base 比同系基础职业高 8-12%，专属属性 10-15% 起步；成长曲线与基础职业同级别。
4. **新机制概率**：反击/格挡反击 15-25%，不屈类每场 1 次封顶，防无限循环。
5. **解锁成本**：Lv.40+ 任务链（约 1-2 周自然进度），不卖数值。
