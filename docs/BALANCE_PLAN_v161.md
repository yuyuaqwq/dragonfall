# v161 职业数值系统性重平衡方案（可持续 DPS 口径）

> 日期：2026-09-02
> 背景：可持续 DPS 模型（速度曲线幂0.5 + 出手频率 + 资源 + 机制/DOT）已落地。
> 现状：梯队严重失衡——刺客 P5 总 DPS 63741 vs 法师 22240（2.9倍），刺客基准太高，全员跟不上。

## 一、失衡根因（三层叠加）

以 P5（Lv95 毕业）为例：

| 职业 | 直伤DPS | DOT | 总DPS | vs 刺客 | 根因 |
|---|---|---|---|---|---|
| 刺客 | 37942 | 25799 | 63741 | 1.00 | cast 0.6 + spd 751 + 腐蚀4层真伤 |
| 游侠 | 26334 | 0 | 26334 | 0.41 | cast 0.65 + spd 707 |
| 战士 | 19543 | 6558 | 26101 | 0.41 | cast 1.2 + spd 519 + 灼烧3层 |
| 法师 | 22240 | 0 | 22240 | 0.35 | cast 1.3 + spd 546 |
| 诗人 | 21879 | 0 | 21879 | 0.34 | cast 0.7 + spd 561 |
| 牧师 | 19736 | 0 | 19736 | 0.31 | cast 0.9 + spd 531 |
| 拳师 | 13097 | 0 | 13097 | 0.21 | cast 0.9 + spd 641 |

**三层失衡**：
1. **频率层**：刺客 cast 0.25（P1）~0.6（P5）全职业最低，spd 全职业最高 → 出手频率碾压
2. **DOT 层**：刺客腐蚀真伤 +51% 输出，战士灼烧 +33%；法师/游侠/拳师几乎无 DOT
3. **直伤层**：刺客 base/ratio 并不低（万毒噬心 base 1991 全表最高），单发也强

## 二、平衡策略（鱼鱼"强了削，弱了加强"）

### 2.1 削刺客（三处收敛，保留"快攻+连段"特色）
| 项 | 现值 | 目标 | 理由 |
|---|---|---|---|
| 刺击 cast | 0.25 | 0.45 | 别碾压（P1 快攻保留但不过分）|
| 链舞 cast | 0.4 | 0.55 | 中段收敛 |
| 万毒噬心腐蚀层数 | 4 | 3 | DOT 51% 太高，降到 ~40% |
| 收割 base | 1011 | 900 | 斩杀略削 |

### 2.2 加强法系（重炮慢速，单发补偿频率）
| 项 | 现值 | 目标 | 理由 |
|---|---|---|---|
| 火球术 ratio | 0.5 | 0.7 | 单发补偿（cast 0.8 慢）|
| 织焰 ratio | 1.2 | 1.4 | 同上 |
| 元素洪流 base | 247 | 350 | 中期补 |
| 万象天雷 ratio | 2.85 | 3.2 | 终极爆发配得上 cast 1.3 |

### 2.3 加强战士/拳师（坦克型半输出）
| 项 | 现值 | 目标 | 理由 |
|---|---|---|---|
| 挥砍 base | 60 | 80 | 坦克型基础保底 |
| 嗜血斩 ratio | 1.22 | 1.35 | 中段补 |
| 直拳 base | 45 | 65 | 拳师基础 |
| 崩拳 ratio | 1.16 | 1.3 | 中段补 |

### 2.4 游侠（A 档，微调）
| 项 | 现值 | 目标 | 理由 |
|---|---|---|---|
| 连射 cast | 0.35 | 0.45 | 收敛频率 |
| 蓄力射击 ratio | 1.39 | 1.5 | 略补 |

### 2.5 牧师/诗人（C 档辅助，不动）
保持辅助定位，DPS 低是设计意图。

## 三、验证方式

1. 改完跑 v161_balance_target.py → 梯队归位
2. 跑 run_numeric_tests.py → 门禁全绿（含击杀轮/Boss单发%）
3. 引擎抽样实测校准（v161_mech_calib.py）→ 机制系数对齐
4. 全绿后提交 + 策划案同步

## 四、风险

- cast 改动影响真实战斗节奏 → 需引擎实测回归（numeric_sim 胜率矩阵）
- 数值改动面大 → 按基线更新流程重标门禁
- 刺客削过头 → 分档验证（P1/P3/P5 梯队都要对）
