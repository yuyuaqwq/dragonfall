## 2. 模型：CD 技"值得用"判据

设 0CD 填充技单发 = d0，周期 = t0（cast×速度折算），则填充技 DPS = d0/t0。
CD 技单发 = d1，CD = c，cast = t1。若玩家在 CD 期间用填充技，则：
- 用 CD 技的循环：CD 技打 1 发 (d1) + 填充技打 c/t0 发
- 纯填充循环：填充技打 (c+t1)/t0 发
- **CD 技值得用 ⟺ d1 > 填充技在 c 秒内的总伤 = d0 × c / t0**

**推论：CD 技单发至少应 = 0CD 技在 CD 周期内总伤害的 55-65%**（留操作/机制容错）
即 `d1 ≥ 0.6 × d0 × c / t0`

举例（游侠）：
- 连射 d0=0.68×atk, t0=0.6s（cast 0.6，spd 基准）
- 致命狙击 c=12 → 需要 d1 ≥ 0.6 × 0.68atk × 12/0.6 = **8.16×atk**（现在只有 1.3×，差 6 倍！）
- 或者反过来：致命狙击保持 1.3×atk，那 CD 必须 ≤ 0.6×1.3/0.68... = 1.1 秒（等于没 CD）

## 3. 修复选项（跨全职业，先建模后选）

### 方案 A：CD 技单发大幅上调（保 CD 机制）
- 按模型把 CD 技 ratio 提到 `0.6×填充DPS×CD/atk` 当量
- 优点：保留"CD 大招"手感；缺点：数值改动面大（299 技能里 ~100 CD 技），且高 ratio 会让满资源/条件触发时爆炸（burst 峰值超红线）

### 方案 B：0CD 技加资源/蓝门槛（压填充频率）
- 游侠连射 mp=0 白嫖 → 改成耗精力（energy 22 已有，但 regen 18/刻 白嫖）→ 调低精力 regen
- 战士挥砍/法师火球都有 mp 但回蓝 5%/行动白嫖
- 优点：保留技能树数值；缺点：动资源经济（v166 模型刚定），影响面广

### 方案 C：CD 技加"使用后强化填充"联动（推荐折中）
- CD 技数值小上调（50-100%）+ CD 期间填充技获得 buff（如致命狙击后 5s 内连射伤害 +50%）
- 让"循环"本身有意义，不靠单发硬超
- 优点：保留节奏感，数值改动温和；缺点：每职业要设计联动规则（工作量大）

### 方案 D：系统性重标（治本，配合现有 skill_vs_basic 门禁）
- 给 skill_scan 加"CD 技 DPS 下限 = 同职业 0CD 技 DPS × 0.6"红线
- 按此红线逐技能标定 ratio（数据驱动改 skills.py exprs）
- 优点：一劳永逸防复发；缺点：改动最大

## 4. 建议

**先做 D 的红线 + 用 C 的思路逐职业修**（不是纯拍数值）：
1. skill_scan/门禁加断言：**CD>0 的输出技 DPS ≥ 同职业最强 0CD 技 DPS × 0.5**（防"练了不如平砍"）
2. 全 299 技能跑此红线 → 列出所有违规 CD 技
3. 按职业批次上修（战士/法师/游侠/刺客/拳师 各一条线），每次过 run_numeric_tests + burst_scan 峰值红线
4. 真引擎抽验修完的流派 vs Boss 确认击杀轮改善

## 5. 影响面
- 数据：skills.py exprs ratio（数据层，纯数据改动，符合"数据驱动铁律"）
- 门禁：skill_efficiency 加 CD 技下限断言

- 顺序：先跑全量违规清单 → 鱼鱼确认修法 → 分职业上修 → 全量测试
