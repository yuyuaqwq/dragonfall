## 阅读说明

### 字段释义

| 字段 | 含义 |
|---|---|
| `lv` | 学习等级（基础技能随等级自动解锁；转职分支按所选流派传承） |
| `mp` | 消耗魔力 |
| `power` | 伤害/治疗倍率（百分比，如 1.0 = 100% 攻击/魔攻） |
| `kind` | 伤害类型：物理 / 魔法 / 治疗 / 增益 / 被动 / 真伤 / 嘲讽 |
| `element` | 元素系：fire 火 / ice 冰 / thunder 雷 / current 当前系 |
| `multi` | 多段攻击次数（每次造成 power 倍率伤害） |
| `aoe` | 范围：front 前排 / all 全体 |
| `pierce` | 破防（无视物理防御） |
| `res_gain` | 核心资源获取（数字 = 每命中 +N；字典 = 指定资源 +N） |
| `res_cost` | 核心资源消耗（如 `rage:3` = 消耗 3 怒气） |
| `consume_all` | 消耗全部资源（`per` = 每点资源额外加成倍率） |
| `cd` | 冷却回合数 |
| `cc` | 控制效果：stun 眩晕 / sleep 睡眠 / silence 沉默 |
| `mech` | 机制附加：burn 灼烧 / poison 中毒 / freeze 冻结 / spd_down 减速 / mark 标记 / shadow 影袭 / poison_burst 毒爆 / cleanse 驱散 / arcane 奥术充能 |
| `mech_val` | 机制层数/回合数 |
| `cond` | 条件增伤（type=条件类型，mult=触发时倍率，label=文案） |
| `team` | 团队效果：atk_all 全队攻击 / matk_all 全队魔攻 / def_all 全队防御 / heal_all 全队治疗 / crit_all 全队暴击 / spd_all 全队速度 / reduce_all 全队减伤 / shield_all 全队护盾 / taunt 嘲讽 |
| `charge` | 蓄力回合数（受击打断；0 表示电荷制蓄力） |
| `passive` | 被动效果 |
| `interrupt` | 打断目标蓄力 |
| `lifesteal` | 吸血比例 |
| `reach` | 射程（1 近战 / 2 远程 / 3 全阵后排） |
