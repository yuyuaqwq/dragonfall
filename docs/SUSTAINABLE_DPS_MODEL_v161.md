## 一、速度曲线（v2 核心变更）

**旧（v154）**：`折算系数 = 50 / min(spd, 80)` —— cap 线性
- 问题：P3 起全员 spd >80（刺客 130、游侠 113），速度属性溢出；cap 内堆速度收益固定

**新（v161，鱼鱼拍板）**：`折算系数 = sqrt(50 / spd)` —— 幂 0.5 边际递减
- 速度 50 → 1.0（基准）；25 → 1.41；100 → 0.71；200 → 0.50；400 → 0.35
- 永不封顶、永不归零、每点速度边际递减 → 堆速度永远有意义、不爆炸
- 引擎 battle.py `_ct_cost` / `_ct_initial_wait` + 模型 `_interval` 已同步

## 二、可持续 DPS 公式（v161 完整口径）

```
可持续DPS = 单发伤害 × 出手频率 × 机制系数 × 资源折算

出手频率 = 1 / (cast × sqrt(50/spd))
机制系数 = 技能机制(按当前技能查) × 职业体系(按职业查)
资源折算 = 空蓝轮数 N；N<战斗长度 → (技能DPS×N + 普攻DPS×(L-N)) / L
```
