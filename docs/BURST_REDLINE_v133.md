# v133 数值体系重构：爆发峰值红线（2026-08-28 鱼鱼拍板）

> 触发：鱼鱼实测"20级裸装刺客 潜行+双刃乱舞 一技能 853 秒 24级主怪 745血（越4级）"。
> 根因：numeric_lib 是均值模型（_crit_mult 期望值 / ROTATIONS 均伤 / variance=0），
> 无"单次行动峰值"维度——v131 只标定了平均轮次，爆发乘区（必暴×暴伤×幸运×条件×多段）
> 全程未约束。
> 鱼鱼拍板：**40% 红线**——单技能峰值 ≤ 同级怪血量 40%（对齐 4~6 轮目标，
> 3 击内绝对带不走同级怪）。

## 一、权威标准（拍板写死）

| 约束 | 数值 |
|---|---|
| 单技能峰值红线 | ≤ 同级怪血量 40% |
| 裸装同级普通怪 | 4~6 轮 |
| 裸装跨5级 | ≤2/8 打不过 |
| 蓝+5 跨5级 | 7 轮勉强 |
| 野外精英 蓝+5 单刷 | 20~35 轮 |
| 野外 Boss 蓝+5 单刷 | 45~80 轮 |
| 副本 Boss 4人蓝+5 | 100~150 轮 |

峰值口径：单次行动（技能）在**全部乘区触发**（必暴窗口/幸运/条件倍率/多段/波动上限）下的伤害。

## 三、峰值口径定义

```
burst_peak = max over 技能s [ atk²/(atk+def') × power × cond_mult × stack ×
             (必暴?1.5:1) × (1+暴伤) × (幸运?1.3:1) × multi段数 × 波动(×1.15) ]
```
含前置：刺客潜行必暴、游侠满弦、武僧蓄力（3气一发按单发算）、条件满血背刺/斩杀线等。

## 四、落地记录（2026-08-28 全量完成）

### 4.1 引擎规则（game/battle.py，防"乘区叠叠乐"治本）

| 规则 | 旧 | 新 | 位置 |
|---|---|---|---|
| 幸运一击倍率 | ×1.5 | **×1.3** | LUCKY_CRIT_MULT（battle_config.py） |
| 多段技能暴击 | 每段独立判定 | **仅首段判定**（seg=0） | MULTI_HIT_CRIT_FIRST_ONLY |

*多段仅首段暴击 = 双刃乱舞/碎骨拳连击段不再各自吃暴×幸运，峰值乘区直接削掉 50%+。*

### 4.2 power 收敛（game/data/skills.py，按 L30+ 稳态截面）

- **基础技能 17 个**：双刃乱舞 147%→17.4%、暗杀→29.4%、旋风斩、雷击等大招类全收敛
  （高低双段技能统一按"多段共享 power + 仅首段暴"重算，均值模型同步升级）
- **分支技能 31 个**：转职线大招同一口径收敛
- 收敛原则：**动 power 优先于动条件倍率**——power 是峰值+均值双乘区，条件倍率只伤峰值；
  首次收敛后发现均值轮次也被砍崩（刺客 20级 13轮），回滚后改为**先收敛峰值乘区（R1/R2 引擎规则），再按需动 power**

### 4.3 门禁固化（tests/test_numeric_burst_redline.py，run_numeric_tests.py 注册）

```
断言：naked/diff0 下 L30/50/70 全部攻击技能 peak_pct ≤ 42（40%+2% 余量）
      L40/60/80 分支技能同口径；刺客潜行路径单独复核
基线：R1/R2 + 17 基础 + 31 分支收敛后，门禁等级超限 = 0
```
