## 5. 亮点

1. **薄弱层收敛 + 白名单防注入**：全部 DB 访问集中在 `game/store/`，`update_player`（`PLAYER_FIELDS`）、`bump_stats`（`STAT_FIELDS`）、`add_prof_exp`（`PROF_FIELDS`）均做列名白名单后拼 SQL，动态列名 SQL 注入/拼错列风险被系统堵死（`players.py:244-246`、`stats.py:27-29`、`professions.py:77`）。
2. **交易/领取类并发原子化到位**：`sell_item_atomic`、`market_buy/stall_sell/exchange_atomic`、`signin_claim`、`props_use_claim_atomic` 全部用 `BEGIN IMMEDIATE` 单事务做读-判-写，并附清晰防“重复发钱/重领”注释——这是该层并发安全的中坚，也是 A1/B4 之外值得保留的正确范式（`social.py:259-331`）。
3. **自愈式 schema 演进**：`_ensure_legacy_columns` 用 `PRAGMA table_info` 惰性 `ALTER ADD COLUMN` 对存量库补列（`connection.py:281-378`），且多数列默认值经注释标明版本里程碑，历史库升级成本低。
4. **脏数据防御体系**：`_jload` 安全 JSON 解析（防 `'null'` 串）、读档 clamp hp/mp、`cur_subarea` 兜底、`stamina` 类型防御（`players.py:97-180`）——针对真实踩过的 E1 列错位事件做了多道防线。
