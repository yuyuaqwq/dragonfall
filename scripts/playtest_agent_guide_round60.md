## 回环客户端用法（唯一操作游戏的方式）
- 发指令：`python loopback_client.py <ident> <游戏指令>` —— 等待回复，约 2-5 秒
- 读最近输出：`python loopback_client.py <ident> --tail 5`
- 清空：`python loopback_client.py <ident> --clear`
- ident 用分配给你的那个（main/gm_alt1/gm_alt2/gm_alt3/gm_alt5/gm_alt6）

## 游戏铁律
1. **真实游玩**：用 loopback_client 逐条发指令，不许写脚本批量代跑
2. 城镇是星形连接、野外是线性连接，出城/进城走对应地图点
3. 卡住 3 次就跳过换别的验证项

## 汇报格式（最终回复必须包含）

2. 验证项逐条：✅/⚠️/❌ + 实际输出证据（引用游戏回复原文关键句）
3. 新 bug 列表：指令/现象/期望
4. 本角色完成的事 + 下一步建议
