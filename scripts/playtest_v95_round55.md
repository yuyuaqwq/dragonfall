- **背景**：main（gm_playtest）在 private 群上下文，与小蓝（gm_alt2，gm_test_group）无法组队（party/副本按 group_id 隔离），player_groups 无 gm_playtest 记录 → 『组队 格温』报"找不到玩家"
- **修复**：① main.py _dispatch 主通道 group_id 也传 gm_test_group（GM 权限不受影响：gm.py _gm_auth 对 gm_ 前缀恒放行，与群上下文无关）② 手动 INSERT player_groups('gm_playtest','gm_test_group') 记录
- **实测**：小蓝『组队 格温』→「🤝 格温 加入了你的队伍！(当前 3 人)」✅ 双方『队伍』互见 ✅ 开本 ✅ 战斗轮流 ✅
- **commit** b016678

### 🔴 #283 副本战斗道具使用：队员视角失效（#269 补充）
- **现象**：副本战斗中 main（队员）『使用 治疗药水』→「你现在的生命是满的(836/836)」走普通分支——队员在副本中无法用药
- **根因（代码实锤）**：economy.py use handler 用 `_in_battle` + `db.get_battle(group_id, qq_id)` 只查自己名下 battle；副本 battle 存队长名下，队员永远查不到 → 走不到 instance 分流（#269 只覆盖队长视角）。对比 combat.py 攻击/技能用 `_instance_battle_for`（先自己再队长）
- **修复**：use handler 战斗分支改用 `_instance_battle_for`（限副本战斗中 boss 非 None，map 模式不误入），副本道具走 `_instance_act("use_item")`
- **实测**：main 副本中『使用 治疗药水(中)』→「💊 恢复 334 点生命！(449/847)」+ 副本界面正常 ✅（Boss 战多次使用）
- **测试**：test_commands_instance 71 + test_commands_economy 35 全绿；commit 8a06154

### 🔴 #281 副本全灭/全退队轮转死循环（卡死 loopback worker，弃游级）
- **现象**：小蓝+格温全倒下、小芽已退队 → 主控发指令全部超时（loopback worker 卡死，AstrBot 主进程正常）；复现：全员倒下后『副本地图』正常但任何战斗指令卡死
- **根因（代码实锤）**：_instance_act 超时推进 while True 循环：退队成员跳过、倒下成员跳过——当所有成员都倒下或退队时**无终止条件无限空转**（全灭判定 987 行只在 Boss 行动后触发，最后一个存活者被反击打死的路径绕过了它）
- **修复**：_instance_act 开头预判 actionable（在队且存活）为空 → 直接 `_instance_defeat` 失败结算（全队回城 hp=0）
- **实测**：全员倒下副本 → 『攻击』→「💀 队伍全灭……副本失败！冒险者们被送回了城镇。」✅ worker 恢复正常 ✅
- **测试**：test_commands_instance 71 全绿；commit 45d1c65
