## 🛠️ 本轮修复（3 项 + 1 系统性）

### 🔴 系统性：elite 混入普通怪物池（57 区域，最高危）
- **现象**：小蓝古树空地探索 3 连遇满血精英狼王·灰影（每次 +358exp/+3 声望），击杀后地图仍同时显示「⭐狼王·灰影 Lv.14」+「⭐ 精英：狼王·灰影」两条重复条目
- **根因**：阶段三生成器把 72 个精英/Boss 挂进子区域 monsters 普通池（80 区域），而 v87 探索逻辑设计"精英独立 8% 判定不混池"——池子抽取绕过判定 → 古树空地 54% 概率遇狼王（8% 字段 + 92%×50% 池子）。6 区域（古树空地/野猪王巢/圣堂地窟/地窖/堡内广场/海妖巢）字段+池子双份
- **修复**：
  ① subareas.py：57 个区域的 elite 条目从 monsters 池移到 elite 字段（8% 独立判定）；18 个 boss 条目**保留池子**（Boss 房必遇，主线任务不卡）；6 个字段+池子重复区域删池子条目
  ② combat.py explore：空池保护——纯精英/Boss 房（野猪王巢等 17 区域）探索不报"什么也没发现"，必遇精英/Boss；空池无 elite/boss 才报空
  ③ world.py map_view：池子条目与 elite/boss 字段重复时不重复显示
- **实测验证**：小蓝古树空地『地图』→「树人 Lv.12 / ⭐ 精英：狼王·灰影」单条显示 ✅；探索遇普通树人 + 精英气息提示「💨 空气中有不寻常的气息……⭐ 此地精英【狼王·灰影】似乎在附近徘徊」✅；影刃橡木平原探索遇普通野兔（非精英）✅
- **补充（d37364d）**：全量扫描发现 57 区域 elite 混池无字段（含橡木平原·溪边草地巨型野猪——#48 验证目标），全部移到 elite 字段；全量回归 80/80 通过

### 🔴 气息调息 0 治疗（拳师生存 bug）
- **现象**：铁拳战斗中『技能 1』(气息调息) →「圣光治愈了你 0 点生命！」→ 战败掉 335 金币
- **根因**：skills.py 气息调息 power=0（desc 说"回复 15% HP"但数值没落地），battle.py 治疗量 = matk×power×倍率 → 0
- **修复**：skills.py power 0→0.15；battle.py `_skill_heal` 支持 power<1 按 max_hp 百分比结算（与消耗品 heal<1 语义一致，治愈术等 power≥1 技能不受影响）
- **实测验证**：铁拳战斗中『技能 1』→「圣光治愈了你 98 点生命！」（655×15%=98.25 ✅ 精确符合 desc）
