## 🛠️ 本轮修复（#252，紧急，commit a6eba7f）

**现象（子 agent 实踩）**：main 实战『盾击』第 3 次成功触发「🌀 敌人被眩晕，跳过下回合！」，但下一回合敌人照常攻击（洞穴蝙蝠 17 伤害），且无「🌀 敌人被眩晕，无法行动！」消费日志——**眩晕效果 0 回合，与描述"强控·单体"严重不符**。

**根因（主控代码实锤 + 复现脚本三路径验证）**：`battle.py _end_round`（1583-1590）对 p_buffs/e_buffs 全部 `-=1` 递减，**stun/freeze 是"行动级"控制（写 1 表示下一次行动被跳过），却在施放当回合就被回合递减吞掉**。三条真实失效路径：
1. **副本路径**：`player_turn(..., enemy_act=False)` → `_enemy_phase` 不调 `_enemy_turn` 直接 `_end_round` → 吞 stun → Boss 回合（instance.py `_instance_boss_turn` 单独调 `_enemy_turn`）查不到
2. **玩家被控路径**：敌方施放眩晕 → 敌方回合结束 `_end_round` 吞 p_buffs stun → 玩家下回合不被控（复现脚本路径2 修复前 ❌ → 修复后 ✅）
3. **敌方先手变体**：e_first 先手一击已打 + e_extra_left=0 → `_enemy_phase` 循环 0 次直接 `_end_round` → 吞 stun → 下回合敌方照常行动

**修复**：`_end_round` 对 `stun`/`freeze` 豁免递减（`if k in ("stun","freeze"): continue`），由行动消费点负责 pop（`_enemy_turn` 1295-1303 / `player_turn` 314-321 被控检查 / 额外行动 265-271）——控制语义变为"跳过下一次行动"，天然覆盖三条路径。

**验证**：复现脚本三路径全 ✅；相关单测全绿（test_v63_control 18 / test_stage6_skills_v2 28 / test_commands_battle 27 / test_commands_instance 71）；**全量回归 80 文件 0 失败（324s）**；AstrBot 重启（6185 LISTEN + aiocqhttp 连接）；loopback 实测：施放盾击后状态栏「🌀眩晕×1」保留，下一回合敌方行动被跳过（无攻击日志直接击杀）✅。
