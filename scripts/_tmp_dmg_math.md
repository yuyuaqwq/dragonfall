## ③ 公式性质：atk/def 比值 → 伤害与等效缩减率（def=100 基准，E.calc_damage variance=0 精确值）

|----------:|----:|----:|-------------------:|--------:|------------------------:|------------------------:|--------------------:|
| 0.5 | 50 | 100 | 16 | 0.320 | 68.0% | 150.0 | 0 |
| 1.0 | 100 | 100 | 50 | 0.500 | 50.0% | 100.0 | 0 |
| 2.0 | 200 | 100 | 133 | 0.665 | 33.5% | 150.0 | 100 |
| 3.0 | 300 | 100 | 225 | 0.750 | 25.0% | 233.3 | 200 |
| 4.0 | 400 | 100 | 320 | 0.800 | 20.0% | 325.0 | 300 |

### ③推导：这是"防御形同虚设"的根源

    dmg = atk²/(atk+def) = atk·(1 + def/atk)⁻¹
         = atk·(1 − def/atk + (def/atk)² − (def/atk)³ + …)
         ≈ atk − def + def²/atk          （atk ≫ def 时）

- 防御的**绝对削减量** = atk·def/(atk+def) < def：无论攻方多弱，防御最多只挡掉"等于自身数值"的伤害，永远不能挡更多；
- 防御的**相对削减率** ε = def/(atk+def) = 1/(r+1)，随 r 增大单调趋 0 —— atk 越高，防御越没用，而不是"按比例"保持有用；
- 反方向同理：被高等级怪打时，玩家的 def 也按同一公式失效 → **失衡双向放大**。
