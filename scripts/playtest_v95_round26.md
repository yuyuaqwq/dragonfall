## 🚨 紧急修复：#155 回环/快捷指令静默无响应（v96.2，commit 0647402）

**现象**：『角色』『攻击』等所有回环指令只回显 `▶ 『角色』` 头，无引擎回复；影刃溪谷战斗中连续『攻击』×5 也全部无响应（同根因）。

**根因（实锤）**：v96.1（c7730af）在 `_find_handler` 加 `name.startswith("_")` 跳过私有 handler，但 AstrBot 加载插件时把 handler 包成 `functools.partial(raw_handler, star_cls)`（star_manager.py 1268 行）——partial **没有 `__name__`**，`getattr(md.handler, "__name__", "")` 恒返回空串 → 跳过条件永不生效 → `_maint_gate`（priority=100 空正则全匹配，排在注册表最前）最先命中所有指令 → 回环身份是 GM（gm_ 前缀）且未停服 → gate 直接 return 不 yield → 静默吞掉。测试环境注册表为空走静态表回退所以 17/17 全绿，真实进程必炸（经典"测试绿线上炸"）。

**修复**：`_find_handler` 取 handler 名先解包 partial（`raw.func`）再 getattr，`shortcut`/`_` 前缀跳过同时生效。

**验证**：test_commands_layer 17/17 通过 → git commit 0647402 → 重启 AstrBot（36004 监听 6185/6199，适配器已连接）→ 回环实测：main『角色』完整面板 ✅、gm_alt6『角色』✅、main『技能』快捷指令 ✅。
