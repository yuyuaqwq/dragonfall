## 🛠️ 本轮修复（#247，紧急）

**现象（子 agent 实踩）**：小蓝 Lv.18 单人走到海蚀洞窟入口（副本地图，Lv.22+ 2-3人 🔒），`_travel_ambush` 移动撞怪从入口子区域 monsters 池（含 b_jack_pirate）随机选中副本 Boss → 直接触发 Lv.28 9435HP Boss 战，无法逃跑，单挑必团灭（损失 10% 金币 3053）。主控实测复现 + 团灭后确认回橡木镇复活（机制正常，非永久卡死）。

**根因（代码实锤）**：
1. `subareas.py` sea_cave 入口 monsters 池含 role=boss 条目（22 副本入口大概率同构）；`world.py _travel_ambush` 移动撞怪 random.choice 不区分 role
2. `combat.py` 探索普通怪池同样不区分 role（Boss 混入 random.choice）
3. `combat.py` 探索精英/Boss 独立判定（SA_BOSS_CHANCE=5%）在副本区域照常生效——探索也有 5% 撞副本 Boss

**修复（3 处）**：
- `world.py _travel_ambush`：`mtype == C.MAP_TYPE_INSTANCE` 直接 return None（副本区域不移动撞怪）
- `combat.py` 探索普通怪池：`role == "boss"` 跳过（Boss 不进普通怪池）
- `combat.py` 探索独立判定：副本类型地图 `sa_elite = sa_boss = None`（副本 Boss 只能走『副本 <名字>』开本流程）

**验证**：test_commands_feedback_features 22 通过 / test_commands_battle 27 通过 / test_commands_instance 71 通过 / test_v87_14_spatial_links 23 通过；重启后 loopback 实测：小蓝走副本入口显示地图信息不撞怪，探索 5 次只遇普通怪【海妖】Lv.24 不再出 Boss ✅。
