> 环境说明：6 角色全汇报（小蓝超时但留下进度，主 agent 接管补测）。**修 1 个紧急 bug（#378/#379 双联，commit 70a448a）**：副本道具使用两处缺陷——同名材料/消耗品『麦酒』劫持『使用』静默失效 + 副本层肃清后道具白扣。主 agent 复核 4 项（#330/#358/#373/#376 实锤 + #378 修复验证）。新 bug 编号 #378 起。

## 🔧 本轮修复（v95r75 #378/#379，commit 70a448a）

**根因链**（格温 Boss 战实锤）：
1. 格温背包有同名『麦酒』×2：材料版 `mat_mai_jiu`（无 heal）+ 消耗品版 `i_ale`（heal 0.15）。`use()` 按名字子串匹配先命中**材料版** → `infer_template` → none 模板
2. 副本战斗分支（economy.py inst_battling）**漏了 battle_ok 检查**（普通战斗分支有）→ none 模板被"执行" → 显示"💊 你使用了战斗道具！"但无效果不消耗，误导玩家
3. 层肃清后（boss=None）使用道具：先执行模板+扣道具，再调 `_instance_act` 被"当前区域的敌人已被肃清"引导 return → **道具白扣无效果**（治疗药水(中)×1 消失、炖菜×3→×2）

**修复**（economy.py 两处）：
- `use()` 匹配逻辑：同名候选优先选**有效果**的条目（heal/mana/stamina/effect），材料版不再劫持
- inst_battling 分支：① boss=None（层肃清）→ 走战斗外路径（模板自行扣道具+播报）② 有 boss → 补 `battle_ok` 拦截（材料类道具明确拒绝）

**验证**：新测试 `tests/test_v95_75_item_use_fix.py` 8/8 ✅；回归 test_v97_07_item_templates 21 ✅ + test_v97_07_quick_battle_use 10 ✅ + test_commands_economy 35 ✅；AstrBot 重启（PID 2024）；loopback 实测：格温『使用 麦酒』→"💊 你使用了【麦酒】，恢复 150 点生命！" 消耗品版扣、材料版保留 ✅
