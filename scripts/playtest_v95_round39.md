## 🛠️ 本轮修复（2 项，commit 0dadb0e）

### 🔴 #216 流星许愿事件报错（探索彩蛋必炸）
- **现象**：铁拳银风商道触发「🌠流星许愿」后『许愿 经验』/『许愿 金币』/『许愿 材料』全部报错「❌ 快捷指令执行出错：'str' object has no attribute 'get'」——事件选项一个都用不了（日志 04:30 复现记录）
- **根因**：events.py shooting_star 模板参数 `"value": "wish_ts"`——但 `tpl_set_state`（event_templates.py:192）只识别特殊值 `"ts"`（存 `{"ts": 时间戳}`），其他字符串原样 `json.dumps` 存库 → event_state 存的是 JSON 字符串 `"wish_ts"` → wish 命令 `json.loads` 得到 str → `st.get("ts")` 在字符串上 AttributeError。v83 落地时写错参数值，两年隐藏至今（彩蛋概率 0.3% 太低没炸过）
- **修复**：① events.py value `"wish_ts"`→`"ts"`（新触发正确存时间戳 dict）② combat.py wish 命令 `json.loads` 后加 `isinstance(st, dict)` 防御——旧脏数据统一按过期处理（提示「流星已经划过天际」优雅降级）
- **实测验证**：向生产库注入旧脏数据 `"wish_ts"` → 小红『许愿 经验』→「流星已经划过天际，你的愿望随风消散了……(下次探索再碰碰运气)」不崩 ✅；铁拳用**真实残留脏数据**实测『许愿 金币』同样优雅降级 ✅（修复前该位置即崩溃点）；测试数据已清理
